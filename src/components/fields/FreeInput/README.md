# 普通单行输入框（`FreeInput`）

`TextInput` 的全站唯一入口，`size="xs"`。**只管输入框这一块**：值、占位文案、标题 / 说明、回车行为都由调用方给。

| 项 | 约定 |
| --- | --- |
| 尺寸 | 固定 `size="xs"`；工具栏里按内容定宽传 `width` |
| 左侧 | 需要图标时走 `leftSection`；搜索语义（搜索图标 + 一键清空）归 `FreeSearchInput`，不要在本组件硬塞 |
| `ariaLabel` | 必填，读屏名（没有可见标签时也要能读懂） |
| `onKeyDown` | 回车等导航行为归调用方，组件自己不抢键 |
| `onFocus` / `onBlur` | 聚焦 / 失焦行为（全选文本、失焦提交）归调用方；`autoFocus` 挂载即聚焦 |
| `styles` | 面板内字段间距这类既有口径，**不在这里写新样式** |

## 什么时候用它

- 普通表单的单行输入（路径、名称、编号这类没有搜索语义的字段）；
- 关键词筛选 / 搜索框用 `FreeSearchInput`，两处不要混用。
