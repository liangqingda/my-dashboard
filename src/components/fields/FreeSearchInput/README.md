# 搜索框（`FreeSearchInput`）

`TextInput` + 左侧搜索图标 + 右侧一键清空，`size="xs"`。**只管输入框这一块**：值、占位文案、
标题 / 说明、回车与快捷键行为都由调用方给。

| 项 | 约定 |
| --- | --- |
| 尺寸 | 固定 `size="xs"`；工具栏里按内容定宽传 `width` |
| 左侧 | 搜索图标恒在，尺寸与标题栏图标同档（15 / 1.9），调用方不再自己拼 `leftSection` |
| 右侧 | 值非空才出现 `CloseButton size="xs"`；点了 `onChange('')` 并**把焦点留在输入框**（继续打字不用再点一次） |
| `ariaLabel` | 必填，读屏名（没有可见标签时也要能读懂） |
| `autoFocus` | 面板一打开就聚焦（筛选面板这类「打开就能打字」）；普通工具栏不传 |
| `onKeyDown` | 回车 / 方向键这类导航行为归调用方（如「Enter 下一个命中」），组件自己不抢键 |
| `styles` | 面板内字段间距这类既有口径（如 `PANEL_FIELD_STYLES`），**不在这里写新样式** |

## 什么时候用它

- 列表 / 看板的筛选工具栏、弹层面板里的关键词输入；
- 业务侧不要再拼 `TextInput` + `CloseButton` / `ActionIcon` 的清空按钮：清空按钮的形态、尺寸与
  「清空后把焦点留在输入框」的行为统一在这里，别在业务里另拼一份。

普通表单的单行输入（没有搜索语义）仍直接用 Mantine `TextInput`；通用输入框口径（`FreeInput`）尚未落地。
