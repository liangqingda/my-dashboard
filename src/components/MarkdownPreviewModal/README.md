# Markdown 预览弹窗（`MarkdownPreviewModal`）

组件规格，跟代码放在一起（非全局性文档不进 `docs/`）。**什么时候必须用它（选型）**归
`docs/ui-components.md` 的「场景 → 用哪个」，本文件只讲它的行为契约与实现约束。

渲染栈固定为 `react-markdown` + `remark-gfm` + `rehype-raw`（需要 GFM 表格与 `<details>` 折叠块）；
新增 Markdown 能力时改这个组件，不要在别处另装渲染器。

职责边界：**调用方**决定「相邻文档是谁」「保存落到哪里」以及「这类文档怎么编辑」（编辑插槽见
`docs/markdown-editing.md`）；**导航与编辑态流程**由组件负责。

## props 契约

| prop | 类型 | 说明 |
| --- | --- | --- |
| `opened` | `boolean` | 是否打开 |
| `title` | `string` | 标题，通常传文件名 |
| `markdown` | `string` | Markdown 原文 |
| `loading` | `boolean`（可选） | 正文是否还在取。为 `true` 时正文区只显示居中加载指示、不渲染 Markdown，标题目录为空且不可点，刷新与编辑入口一并收起（没有正文可编辑，也不该把空串写成一篇空文档）。打开 / 翻篇 / 刷新过程中由调用方传 |
| `position` | `{ index: number; total: number }`（可选） | 展示「第几 / 共几」 |
| `relativePath` | `string`（可选） | 文档的相对路径（相对其记录仓库根目录）；提供后 header 出现复制图标按钮，不传则不显示。组件不拼路径，由调用方给 |
| `onClose` | `() => void` | 关闭 |
| `onPrevious` | `(() => void) \| null`（可选） | 上一篇；`null` 表示到头，按钮置灰 |
| `onNext` | `(() => void) \| null`（可选） | 下一篇；`null` 表示到头，按钮置灰 |
| `onRefresh` | `(() => Promise<void> \| void) \| null`（可选） | header 右侧操作组里的刷新按钮；调用方重取最新正文并回灌 `markdown`，返回 Promise 时按钮显示 loading，不传则不显示；编辑中不渲染（刷新会把草稿盖掉） |
| `onSave` | `(markdown: string) => Promise<{ notice?: string }>`（可选） | 提供后才出现「编辑」；落盘由调用方实现，抛错则显示为保存失败，返回的 `notice` 追加在「已保存」提示后 |
| `Editor` | `ComponentType<MarkdownEditorProps>`（可选） | 这一类文档的定制编辑器；不传则点「编辑」只给定制提示 |

## 行为细节

### 文档排版

标题、表格、引用、代码块、`<details>` 折叠讲解等都由组件负责，调用方只给原文。

### 导航

header 里、**标题左侧**的上一个 / 下一个图标按钮，配合 `←` / `→` 快捷键。

### 复制相对路径

header 右侧的复制图标按钮（排在刷新之前、只在预览态出现），**调用方传 `relativePath` 才出现**：

- 点一下把这串相对路径（相对文档所在记录仓库根目录，如 `learning-record-notes/x.md`）写进剪贴板，
  图标 1.5 秒内变成对勾；尺寸与同排图标同档（15px / sm），**编辑态与草稿预览不显示**；
- 路径由调用方拼，组件不假设文件落在哪里（按钮本体是公共的 `src/components/CopyIconButton`）。

### 标题导航（左侧目录列）

弹窗**左侧固定的一列**文档内 h1–h4 目录 sidebar，按层级折成树：

- 每深一层向右缩进一段、左侧多一条极淡的引导线（顶层不画线），层级靠线 + 字号 / 颜色区分；
- 字号基准按全屏写（行 13.6px、一级 14px、其余 12.9px），**非全屏由目录列统一减 2px**
  （改一个 `--outline-shrink` 变量即可，Item 里的字号都是 `calc(基准 - var(--outline-shrink))`）；
- 有子标题的节点在标题右侧带折叠图标（右对齐）；
  **常规只展开第一个节点及其第一个子级，全屏预览时默认全部展开**；
- 点标题会跳转并顺带展开，收起只能点图标；**滚动正文时目录跟随高亮当前所在的小节，并把它的祖先链
  补展开**、高亮行滚出目录可视区时自动滚回来（手动收起同一分支会保留，直到滚到别的小节）；
- 编辑态没有正文可测量，激活项取「最近一次跳转到的标题」（不跟编辑器滚动联动），进入 / 退出编辑时清空；
- 目录占独立一列（常规 184px、全屏 300px）、高度由布局自然拉伸、只在目录列内滚动（不再测量正文高度
  封顶），滚动条贴右边缘、做细；窄屏（≤720px）目录挪到正文上方一条横带、最多占三成高度。

### 正文渲染性能

正文渲染结果必须用 `useMemo` 包住（只依赖 `renderedMarkdown`）：`react-markdown` 每次渲染都会重新解析
整篇，正文节点挂载、刷新、编辑态切换这类内部状态变化时重解析一次就是几十毫秒的「点开卡一下」。

### 全屏预览

header 右侧的图标按钮（排在刷新之后、编辑操作之前；编辑态不显示），点了把整个框体铺满视口
（去外边距、描边与圆角），目录默认全展开且列加宽，正文行宽收在一栏并居中，只放大可读高度。

- 全屏期间 Esc 只退出全屏（不关弹窗）；
- **全屏是记住的偏好**（`localStorage`，键见 `constants.ts` 的 `FULLSCREEN_STORAGE_KEY`）：换篇、关掉重开、
  刷新页面后再打开都还是上次的样子，关闭弹窗不会把它重置成常规大小。

### 换篇（上一篇 / 下一篇）

**不重挂弹窗、不退出全屏**——全屏是「怎么看」，不属于某一篇。属于「这一篇」的复位由组件自己做：

- 保存状态提示带着所属标题存（标题对不上就当没有提示，`SaveHintState`）；
- 正文滚回顶部（`hooks/useDocumentScrollReset`）。

调用方**不要**用 `key={文件名}` 重挂弹窗来清换篇状态，那会把全屏一起重置，表现为切一篇就掉出全屏。

### header 与保存状态

**弹窗没有 footer**：编辑 / 预览 / 保存 / 放弃改动与状态提示全部收进 header 右侧，只留图标 + tooltip
（`aria-label` 与 tooltip 同一句人话）：

- 未编辑时是「编辑（铅笔）」；进入编辑态换成「退出编辑（返回箭头）/ 预览草稿（眼睛）/ 保存（对勾，主色）」；
- 右侧图标分成两组：**文档操作组**（复制路径 / 刷新 / 全屏）在前，**编辑流程**在后，两组之间一条竖分割线；
- **编辑态与草稿预览只保留编辑流程这一组**（退出、预览、保存），文档操作组整组不渲染——新增这类按钮
  放进 `TitleBar` 的 `documentActions` 组即可，不必每个再判一次编辑态；
- 竖分割线与「给关闭按钮让出的间距」只在文档操作组出现时才有（编辑态没有关闭按钮，也不留这段）；
- 保存成功在图标左侧显示「已保存・HH:MM」并在 3 秒内淡出（连续保存不会互相踩定时器）；
- 编辑态（含草稿预览）那排图标放大一档（18px 图标 / lg 按钮），非编辑态（只有铅笔）与刷新 / 全屏 / 关闭
  同档（15px / sm）；
- 保存失败显示红色错误文案，超长时省略、hover 弹完整内容。

### 编辑态不可关闭

**编辑态（含草稿预览）弹窗根本关不掉**：

- 关闭按钮不渲染；Esc 与点遮罩都只弹一条「编辑中不能关闭预览」的提示（固定 notification id，连按不会
  叠一屏；草稿预览态提示走「返回编辑」那条路）；
- 全屏按钮也收掉（全屏只会把块编辑器抻大）；
- 唯一出口是「返回箭头」：先退出编辑，关闭与全屏才回来。

### 草稿预览

编辑态点「预览」把正文换成草稿的渲染结果（编辑器只隐藏、不卸载，草稿 / 撤销栈 / 光标都留着），
header 的操作缩成「返回编辑」「保存」；点「返回编辑」回到编辑态接着改，点「保存」才落盘。
预览草稿期间跨文档的 `<` `>` 与 `←` `→` 仍禁用（避免草稿被换掉）。

### 编辑插槽

组件**不带默认编辑器**，具体编辑界面由调用方通过 `Editor` 传入；没有传 `Editor` 时点「编辑」只弹提示。
编辑器可选实现 `onHandleReady(handle | null)`：交上来一个 `revealHeading(index)` 就能让编辑态的标题目录
可用（编辑态正文不渲染，目录只能由编辑器自己定位）；不实现时编辑态点目录没有反应。
实现方式与各文档类别的编辑器见 `docs/markdown-editing.md`。

### 退出编辑保护

编辑中且有未保存改动时，点「返回箭头」先在 header 二次确认（提示「这份改动还没保存」+
「继续编辑（返回箭头）」/「放弃改动并退出编辑（红色垃圾桶）」），不会静默丢改动；确认放弃只是退出编辑态，
弹窗仍开着（这时才轮到关闭）；编辑态标题目录保持可点（由编辑器定位到对应块），不再是置灰的死列。

### 关闭、键盘可访问性与焦点管理

关闭入口、Esc / 遮罩行为、焦点进出弹窗都按 Mantine `Modal` 的既有能力处理，自定义按钮一律带
`aria-label`（与 tooltip 同一句话）。
