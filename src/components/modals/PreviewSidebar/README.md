# PreviewSidebar

媒体预览的**唯一列表侧栏**：视频预览与图片预览共用，列当前目录里同一类型的条目、
高亮正在看的那一条。它不是 `FreeXxx`（不构成外观基线，也不是全站唯一形态）：
锁的是一份「媒体预览的目录列」的排布与交互。

## 它锁了什么

- 结构：标题 + 条数（头）→ 可滚动的条目列表；整块与弹窗 header 同一档软底
  （`--preview-chrome`），右侧一条 `--app-line` 细线与舞台分开；
- 条目：整行可点，图标在前、名字占满剩余宽度并做中间省略（`FreeTruncatedText`），
  名字太长也不把行撑破；当前这条用 `aria-current` + 选中底色标出；
- 媒体图标统一蓝色、选中态走 `--app-accent`，不在调用方各写一份颜色。

## 它不管什么

- 条目的类型与图标：`icon` 由调用方给（视频传 `IconVideo`、图片传 `IconPhoto`），
  侧栏不判断文件分类；
- 翻篇边界（到头是否循环、按不按键翻）：状态与快捷键都在弹窗里，侧栏只把点选回传；
- 条目的排序与过滤：列表由调用方按当前目录筛好（顺序即翻篇顺序）。

## props

| prop | 说明 |
| --- | --- |
| `title` | 侧栏标题（如「当前目录视频」），单行不换行 |
| `icon` | 每条前面的图标节点；尺寸 / 线宽由调用方定 |
| `items` | `{ id, name }` 列表，顺序即翻篇顺序 |
| `activeId` | 当前预览中的条目 id，用来高亮 |
| `onSelect` | 点选某一条（只回传 id，切不切得动由弹窗判断） |

## 现有用法

- `VideoPreviewModal`：可显隐（全屏默认收起，`S` 键切换）；
- `ImagePreviewModal`：常驻展示。
