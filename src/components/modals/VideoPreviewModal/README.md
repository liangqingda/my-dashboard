# 视频预览弹窗（`VideoPreviewModal`）

视频预览的**唯一入口**：文件页里的视频条目点开后，在 `FreeModal` 里播放、翻篇、看当前目录
的视频列表、截当前一帧、改播放偏好（方向键去向 / 步长 / 空格去向 / 截图目录 / 悬停预览大小）。
它只做「容器」——播放能力组合自独立的 [`FreeVideo`](../../file-preview/FreeVideo/README.md)
（`file-preview` 分类），本组件不重复实现控制栏与播放状态；截图落盘交给调用方。选型见 `docs/ui-components.md`；本文件讲行为契约与实现约束。

## 它锁了什么

- **组合关系**：`FreeModal`（外壳：标题 / 翻篇 / 计数 / 键位）+ `FreeVideo`（播放器）+
  `PreviewSidebar`（目录，与图片预览共用）+ `VideoSettingsPopover`（设置）。播放器与弹窗互不依赖：
  `FreeVideo` 不认识弹窗，弹窗只传 `src` 与 `videoRef`；全屏、header、侧栏、设置、截图都留在本组件。
  整屏全屏的 hook 也已上提到 `src/hooks/useBrowserFullscreen.ts`（与图片预览共用一份）。
- **header**：标题与右侧操作组之间恒留 20px（外壳 `.titleGap` 保证），标题单行不换行、
  放不下才省略，hover 时用 tip 展示全名。操作组固定在标题右侧：目录显隐 → 截图 →
  外部打开 → 设置（前三颗与外部打开由 `VideoHeaderActions` 排，设置那颗留在弹窗里接设置值）；
  删除排在全屏之后（`headerTail`，最右），关窗前一条竖线由外壳画。
- **整屏全屏**：走浏览器 Fullscreen API（`document.documentElement.requestFullscreen()`），
  占的是**整块屏幕**，不是把框体撑满视口。`fullscreenchange` 是唯一状态源：浏览器里按 `Esc`
  退出全屏的状态也由它同步，组件不自己猜。
- **header 自动隐藏**：只在「全屏且侧栏收起」时生效——此时 header 是浮层（绝对定位覆盖画面顶部），
  鼠标静止 1s 收起（淡出上移、不接收指针事件），鼠标一移动 / 按下 / 滚轮就重新浮出并重置计时。
  **指针在播放器控制栏上时不唤出 header**（`FreeVideo` 的 `data-video-controls` 区域被
  `useAutoHideHeader` 的 `ignoreSelector` 排除）：划过播放条不该把 header 一起带出来。
  侧栏一唤出，header 回到普通流：浮层会盖住侧栏顶部，回到流里侧栏才完整可见。
  指针停在 header 自身那一行时不收起（`MODAL_HEADER_SELECTOR` 作为 hold 区）：把指针移出 header、
  移到控制栏之外才开始计时收起，不会「看着按钮它却淡下去」。
  设置面板 / 删除确认开着时暂停自动隐藏，免得面板跟着 header 一起藏起来。
- **侧栏**：列当前目录的全部视频（顺序 = 翻篇顺序），高亮正在播放的一条，整行可点切换。
  常规尺寸默认显示；**进全屏默认收起**，由 header 的列表图标按钮唤出。两份开关分开记：
  全屏收起不影响常规尺寸。
- **控制栏的两颗箭头**：排在**播放键左右两侧**（`FreeVideo` 的 `nav`），跟控制栏一起显隐——
  暂停恒在，播放中随画面一起收起，不常驻挡画面。**去向与实体方向键同一套**（同一个
  `settings.arrowMode`）：seek 模式是「后退 / 前进 N 秒」，nav 模式是「上一个 / 下一个视频」，
  文案跟着变，到头的一侧置灰。
- **header 的翻篇按钮**：`[` / `]` 翻篇照旧，与控制栏箭头的 nav 语义互相独立。
- **外部打开**：header 的「斜箭头」按钮把当前视频交给本地播放器（`onOpenExternal`）——
  浏览器解不动的编码或想更快起播时走这条；组件只把条目 id 交回去，用什么应用、怎么提示归调用方。
- **截图**：header 的相机图标把当前视频帧画进离屏 canvas（PNG），连同设置里的目录一起交给
  调用方落盘；失败 / 还没解出画面各给一条通知，不生成空白图。截图不改播放状态，暂停时截当前帧。
- **键盘**：全部由 `FreeModal` 判，本组件只给动作——
  - `空格`：按设置**播放 / 暂停**（`media`，默认）或**关闭弹窗**（`closeOnSpace`）；
    两种只占一种——设置成关窗时就不传 `onTogglePlay`，否则空格会同时播一下又关掉；
  - `Enter`：截当前一帧（`onCapture`，与 header 的相机按钮同一口径）；
  - `m` / `M`：静音 / 取消静音（`media.onToggleMute`，直接翻 `<video>` 的静音位）；
  - `s` / `S`：显示 / 隐藏视频列表（`onToggleSidebar`，与 header 的列表按钮同一口径）；
    全屏里侧栏一唤出，header 也随之回到视野（浮层让位给普通流），设置面板的速查表就按这个口径写；
  - `[` / `]`：上一个 / 下一个（到头不循环）；
  - `←` / `→`：**按设置快进 / 后退**（默认 10s）；设置里改成「切换上下条」后就回到翻篇，
    这时 header 的翻篇 tooltip 也换成带方向键的口径；
  - `F`：整屏全屏；`Esc`：全屏里交给浏览器退出全屏，非全屏才是关窗；
  - `Delete` / `Backspace`：触发删除确认（只打开确认层，不直接删）；确认层弹出前先把片子暂停，
    取消后若是弹窗停的才续播——原本就是暂停状态的，取消后仍停在原处。
  - 设置面板打开、或删除确认开着时，整组键位与焦点陷阱交给那一层，底下播放器不再响应。
- **设置面板**：`IconPopoverButton` 弹出的一档设置，按主题分成三组（浅底色块，走
  `FreePanelGroup` / `FreePanelField`，与文件页设置面板同一套外观）：
  1. **播放**：快进 / 后退步长（1–600 秒，默认 10）、`←` / `→` 去向（快进后退 / 切换上下条，
     控制栏那两颗箭头跟着同一套）、空格键去向（播放 / 暂停 / 关闭弹窗）、
     **悬停预览大小**（进度条悬停帧图宽占画面宽度的比例，30%–90%，步长 5%，默认 60%；
     存整数百分比，传给 `FreeVideo` 时除以 100，最小 30% 是「再小就认不出画面」的下限）；
  2. **截图**：截图存放位置（默认「桌面」），可用系统目录选择框改到任意目录，
     **不提供「恢复默认」**——想回默认就手动选回原目录；
  3. **快捷键**：全部键位速查，双列排，一屏看完；「空格」与「方向键」两行随设置变，其余固定。
  面板宽度按双列快捷键与三列字段定（`SETTINGS_PANEL_WIDTH`）。
  偏好存成一个 JSON 对象（`<页面标识>:video-preview`），由 `storageScope` 决定命名空间。
- **关窗口径**：点遮罩关窗（`FreeModal` 的默认行为），只是窗口刚拿回焦点的那 400ms 内不算——
  从 IINA 之类的外部应用切回来的第一下点击只当回焦，不会误关；
- **默认全屏**：`defaultFullscreen` 为真时，每次打开都尝试进整屏（文件页设置里的「视频预览打开即全屏」）；
  浏览器没拿到用户手势会静默停在这个尺寸，不弹失败提示，`F` 仍可手动切换；
- **翻篇与计数**：`FreeModal` 的 `nav`，到头置灰不循环；换片用 `key` 重挂播放器实例，
  不重挂弹窗（全屏与侧栏状态不跟着重置）。

## props

| prop | 说明 |
| --- | --- |
| `opened` | 是否打开 |
| `items` | 当前目录的视频：`{ id, name, src }`，`id` 由页面给（文件页用路径） |
| `activeId` | 当前条目；不在 `items` 里时组件不渲染内容（调用方应同时关窗） |
| `storageScope` | 页面标识（对应路由），拼设置项的存储键；组件不写死是哪一页 |
| `onSelect` | 切到某一条（翻篇、侧栏点选与舞台按钮共用） |
| `onClose` | 关闭（内部会先退出整屏） |
| `onCapture` | 把 PNG data URL 与目标目录（空串 = 桌面）交给页面落盘，返回 `{ message }` |
| `onOpenExternal` | 用外部播放器打开当前视频（页面实现 IINA 优先、回落系统默认）；不传则 header 没有那颗按钮 |
| `onPickDir` | 调系统目录选择框选截图存放目录；返回 `null` 表示取消。不传则路径没有「选择目录」 |
| `onRequestDelete` | 请求删除当前视频：只应打开二次确认层；不传则没有删除按钮与 `Delete` 键 |
| `blocked` | 删除确认开着：整组快捷键与焦点陷阱交给确认层 |

弹窗**不知道**文件在哪、桌面在哪：路径、选择框与落盘都由调用方实现；组件只给「当前帧 + 目标目录」。
`onCapture` 的目录是用户偏好的原样字符串（空串表示默认），由调用方的落盘接口解释成真实路径。

## 实现约束

- `FreeVideo` 只认 `src` / `videoRef` / `nav` / `previewScale` / `className`；视频元素引用交给弹窗复用
  （截图、空格播放、静音与方向键快进都读它）。
- 方向键快进直接改 `<video>` 的 `currentTime`，进度与时间文本由元素自己的 `timeupdate` 同步，
  不在弹窗里另存一份进度。
- 换片是 `key={id}` 重挂 `FreeVideo`——在同一个 `<video>` 上换 `src` 需要清理播放状态与进度，
  重挂比在 effect 里逐项复位更省心。
- 浏览器解不了的编码（mkv / avi / wmv 等常见）走 `error` 事件，舞台中央给一句人话，
  不静默停在黑屏；暂停时舞台中央**不放大播放键**，点画面或按空格都能继续播。
- 本组件内部的键盘监听为**零**：能按的键都在 `FreeModal`（播放、静音、目录列、翻篇、方向键、全屏、删除）里判，
  业务层不自己 `addEventListener('keydown')`。
- 视频流由 Vite 中间件 `GET /api/files/content` 按 Range 提供，截图由 `POST /api/files/capture`
  写进设置里的目录（默认桌面）；两者都只在开发模式存在（见 `docs/local-repo-data.md`）。
- `utils/seek.ts` 只算「挪到哪个时间点」，写回 `currentTime` 留在弹窗，
  避免挪动逻辑（含 NaN 时长兜底）在控制栏与方向键两处各写一遍。
