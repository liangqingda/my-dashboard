# 视频预览弹窗（`VideoPreviewModal`）

视频预览的**唯一入口**：文件页里的视频条目点开后，在 `FreeModal` 里播放、翻篇、看当前目录
的视频列表（选集弹层）、截当前一帧、把当前这条加进 / 移出调用方的待拖拽区、
改播放偏好（方向键去向 / 步长 / 空格去向 / 截图目录 / 悬停预览大小）。它只做「容器」——播放能力组合自独立的 [`FreeVideo`](../../file-preview/FreeVideo/README.md)
（`file-preview` 分类），本组件不重复实现控制栏与播放状态；截图落盘交给调用方。选型见 `docs/ui-components.md`；本文件讲行为契约与实现约束。

## 它锁了什么

- **组合关系**：`FreeModal`（外壳：标题 / 翻篇 / 计数 / 键位）+ `FreeVideo`（播放器，控制栏与
  操作组都在它里面）+ `VideoSettingsPopover`（设置）。播放器与弹窗互不依赖：`FreeVideo` 不认识弹窗，
  弹窗只传 `src`、`videoRef` 与控制栏右侧的操作组；全屏、设置、截图都留在本组件。
  整屏全屏的 hook 也已上提到 `src/hooks/useBrowserFullscreen.ts`（与图片预览共用一份）。
- **布局（B 站式）**：舞台只留画面，操作全部收进播放器底部控制栏——进度条独占上层；下层左侧是
  前后 / 播放 / 时间，右侧依次是喇叭、选集、删除、截图、外部打开、加入 / 移出待拖拽区、设置、
  网页全屏、整屏全屏。
  header 只留标题与外壳关闭按钮，不再放业务操作。
  整屏全屏或网页全屏时给 `FreeVideo` 传 `expanded`：播放键与前后箭头的图标放大一档，按钮盒子与间距不变；
  画面仍完整显示、**不裁**：全屏时屏幕比例由设备定，16:9 的片子放在 16:10 的屏幕上 `contain`
  会上下留空带，那两条空带由 `FreeVideo` 的模糊空带底填上（同一帧缩略图放大虚化），不再是死黑。
- **画面框跟随片源**：普通窗里正文框按片源宽高比在可用区域内取最大矩形（宽度 ≤ 外壳宽度档
  `--modal-size` 与内层两侧 5vw 内边距后的 90vw、高度 ≤ 阅读窗的 `88dvh`，并按高度上限反算宽度），
  视频正好填满这一框——`object-fit: contain` 原来留在
  舞台里的上下黑边就此消失，画面本身**不裁、不拉伸**。比例由 `FreeVideo` 解出元数据时报上来
  （`onAspectChange`）；换片**沿用上一段的比例**，等新片子报自己的，不先跳回兜底 16:9 再跳一次
  （那两下尺寸重算就是切上 / 下一段时弹窗闪的来源）。
  - **两种全屏不走这条**：屏幕比例由设备定，框就铺满屏幕；16:10 屏上看 16:9 片仍会剩一条窄边，
    这是几何必然，只有裁切铺满才消得掉（代价是切掉边缘画面）。
  - **竖屏片**：不再保底 480px 宽，改由高度上限把框收窄——宁可框窄也不留两侧黑边；
    控制栏在窄框里会挤一些，这是「画面优先」的取舍。
- **两种全屏**：
  - **网页全屏**：框体铺满视口（`100vw / 100dvh`，去掉描边圆角与内层两侧 5vw 内边距），
    不调浏览器 Fullscreen API；当作「怎么看」的偏好记在设置里，重开 / 刷新后保持。
  - **整屏全屏**：走浏览器 Fullscreen API（`document.documentElement.requestFullscreen()`），
    占的是**整块屏幕**。`fullscreenchange` 是唯一状态源：浏览器里按 `Esc` 退出全屏的状态也由它同步，
    组件不自己猜；`F` 键切的是这一档。
  两种全屏都通过 `FreeModal` 的 `fullscreen.reportActive` 上报程序坞：进入时程序坞条与右下角控件先收起，
  全屏期间又被收进新窗口弹出来时才降透明度。
- **header 自动隐藏**：走 `FreeModal` 的 `headerOverlay`（与图片预览共用同一套浮层外观，
  细则见 `FreeModal/README.md`）：打开即是收起态——先看画面，第一次动鼠标才浮出，鼠标静止 1s 收起
  （淡出上移、不接收指针事件），一移动 / 滚轮就重新浮出并重置计时。
  **指针停在 header 上时不收起**（正要点某颗按钮它却淡下去），移到 header 以外就重新计时收起；
  设置面板 / 删除确认开着时 `suspended` 暂停唤出，免得面板跟着 header 一起藏起来。
  **控制栏（footer）与之同一套节奏**（见 `FreeVideo`）：打开即收起态、指针一动浮出、静止 1s 收起，
  暂停 / 播完也不再常驻——两层 chrome 跟着同一片指针活动一起浮出、一起收掉。
  只有「操作控制栏时不唤出 header」这一条各自为政：控制栏根节点带 `data-video-controls` 标记，
  弹窗用 `VIDEO_CONTROLS_SELECTOR` 传给 `ignoreSelector` 圈掉这块区域——在上面挪指针是想操作播放，
  不该顺带把标题栏顶出来；指针一进控制栏 header 就收起，回到画面才浮出。
  **反过来也对称**：指针落到 header 上时，控制栏由 `hideControlsOnSelector`（弹窗传 `FreeModal`
  导出的 `MODAL_HEADER_SELECTOR`）当场收起、不重新计时。两边各管各的显隐，指针只在其中一层时，
  另一层不会还挂在画面上。
- **tip 与控件配色**：弹窗内所有 hover 提示（标题截断、控制栏按钮、选集条目、设置滑杆浮标）固定深底浅字，
  header 与控制栏的标题、图标、时间同步取媒体浮层浅字档，都不随主题反转——控件压在视频画面上，
  浅色 chip 在暗画面上跳不出来。
- **选集**：控制栏右侧的「选集」按钮，点一下浮出当前目录的全部视频（顺序 = 翻篇顺序），
  高亮正在播放的一条，整行可点切换并合上弹层；再点按钮 / 点外部 / Esc 收起，不做常驻侧栏。
  弹层开着时按钮保持主色高亮（与设置那颗同一套壳），弹层开在按钮正上方；
  弹层高度封顶 `min(320px, 60dvh)`，条目再多在弹层内部滚，不顶出弹窗底部。选集 / 设置任一弹层开着时点画面，只收弹层、不切播放。
  两档弹层统一走 `DOCK_POPOVER_Z_INDEX`（1020）：页面窗里不被展开的程序坞条盖住，程序坞恢复窗里也压过
  窗口本身（1000）与程序坞条（1010）。
- **切换计数**：换条（按钮 / 选集 / `[` `]` 翻篇，以及删掉当前这条后顺位切到下一条）后预览区左上角
  浮出一下「3 / 12」，1 秒后自己收掉（`PreviewCounter`，与图片预览同一份）：切换序号（`switchTick`）由持有
  `activeId` 的那一层统一产出，弹窗不在各个 handler 里另数一份；header 是浮层且默认藏着，所以计数单独浮出，不连带 header。
- **控制栏的两颗箭头**：排在**播放键左右两侧**（`FreeVideo` 的 `nav`），跟控制栏一起显隐——
  暂停也随画面一起收起，不常驻挡画面。**去向与实体方向键同一套**（同一个
  `settings.arrowMode`）：seek 模式是「后退 / 前进 N 秒」，nav 模式是「上一个 / 下一个视频」，
  文案跟着变，到头的一侧置灰。
- **双击画面切整屏**：双击播放区进出整屏全屏（与 `F` 同一档，走同一个 `useBrowserFullscreen`）。
  单击那一下切成播放 / 暂停要等一个双击窗口（`@/hooks/useSingleOrDoubleClick`，300ms），
  第二下到来就把这次播放 / 暂停作废——双击只换尺寸，**播放态一点都不动**（不会先 pause 再 play）。
  删除确认开着时不传双击动作（确认层盖着舞台，也不该在这时换尺寸）。
- **外部打开**：控制栏的「斜箭头」按钮把当前视频交给本地播放器（`onOpenExternal`）——
  浏览器解不动的编码或想更快起播时走这条；组件只把条目 id 交回去，用什么应用、怎么提示归调用方。
- **截图**：控制栏的相机图标把一帧（PNG）连同设置里的目录一起交给调用方落盘。截哪一帧看浮层：
  悬停预览正显示某帧时存**浮层里这一帧，而不是指针此刻指向的那一秒**（帧要停稳才换，指针刚挪时
  两者会差一小段）——帧自己的时间与画面同源，播放器按探针在该时间取全分辨率原图：探针就在那一帧
  上就立刻画，不在（帧图走了缓存）就补一次 seek 再画——这一步可能要等解码，按钮一直转圈；
  真解不出画面才退回浮层里那张缩略帧。没有悬停帧才存当前播放画面。失败 / 还没解出画面各给一条通知，不生成空白图。截图不改播放状态。
- **键盘**：全部由 `FreeModal` 判，本组件只给动作——
  - `空格`：按设置**播放 / 暂停**（`media`，默认）或**收进程序坞**（`closeOnSpace`，不可收起时无动作）；
    两种只占一种——设置成收起时就不传 `onTogglePlay`，否则空格会同时播一下又收起；
  - `Enter`：截一帧（`onCapture`，与相机按钮同一口径）；悬停预览正显示某帧时截的是那一帧；
  - `m` / `M`：静音 / 取消静音（`media.onToggleMute`，直接翻 `<video>` 的静音位）；
  - `[` / `]`：上一个 / 下一个（到头不循环）；
  - `←` / `→`：**按设置快进 / 后退**（默认 10s）；设置里改成「切换上下条」后就回到翻篇，
    这时翻篇 tooltip 也换成带方向键的口径；
  - `F`：整屏全屏；`Esc`：全屏里交给浏览器退出全屏，非全屏才是关窗；
  - `Delete` / `Backspace`：触发删除确认（只打开确认层，不直接删）；确认层弹出前先把片子暂停，
    取消后若是弹窗停的才续播——原本就是暂停状态的，取消后仍停在原处。
  - 设置面板打开、或删除确认开着时，整组键位与焦点陷阱交给那一层，底下播放器不再响应。
- **设置面板**：`IconPopoverButton` 弹出的一档设置，按主题分成三组（浅底色块，走
  `FreePanelGroup` / `FreePanelField`，与文件页设置面板同一套外观）：
  1. **播放**：快进 / 后退步长（1–600 秒，默认 10）、`←` / `→` 去向（快进后退 / 切换上下条，
     控制栏那两颗箭头跟着同一套）、空格键去向（播放 / 暂停 / 收进程序坞）、
     **悬停预览大小**（进度条悬停帧图宽占画面宽度的比例，30%–90%，步长 5%，默认 60%；
     存整数百分比，传给 `FreeVideo` 时除以 100，最小 30% 是「再小就认不出画面」的下限）；
  2. **截图**：截图存放位置（默认「桌面」），可用系统目录选择框改到任意目录，
     **不提供「恢复默认」**——想回默认就手动选回原目录；
  3. **快捷键**：全部键位速查，双列排，一屏看完；「空格」与「方向键」两行随设置变，其余固定。
     空格设为「收进程序坞」时，对能收起的预览改走「收进程序坞」，只有 X / Esc 真关。
  面板宽度按双列快捷键与三列字段定（`SETTINGS_PANEL_WIDTH`）。
  偏好存成一个 JSON 对象（`<页面标识>:video-preview`），由 `storageScope` 决定命名空间。
- **关窗口径**：已收录到程序坞的窗，点遮罩 / X / Esc / 空格收回程序坞；未收录的普通弹窗正常关闭。
  窗口刚拿回焦点的那 400ms 内不算——从 IINA 之类的外部应用切回来的第一下点击只当回焦，不会误关；
- **默认全屏**：`defaultFullscreen` 为真时，每次打开都尝试进整屏（文件页设置里的「视频预览打开即全屏」）；
  浏览器没拿到用户手势会静默停在这个尺寸，不弹失败提示，`F` 仍可手动切换；
- **翻篇与计数**：`FreeModal` 的 `nav`，到头置灰不循环；换片用 `key` 重挂播放器实例，
  不重挂弹窗（全屏与网页全屏状态不跟着重置）。

## props

| prop | 说明 |
| --- | --- |
| `opened` | 是否打开 |
| `items` | 当前目录的视频：`{ id, name, src }`，`id` 由页面给（文件页用路径） |
| `activeId` | 当前条目；不在 `items` 里时组件不渲染内容（调用方应同时关窗） |
| `storageScope` | 页面标识（对应路由），拼设置项的存储键；组件不写死是哪一页 |
| `switchTick` | 计数浮标的切换序号：由持有 `activeId` 的那一层（文件页是 `usePreviewList`）在翻篇 / 选集点选 / 删除后顺位切换时加一；打开与关窗归零 |
| `onSelect` | 切到某一条（翻篇、选集点选共用） |
| `onClose` | 关闭（内部会先退出整屏） |
| `onCapture` | 把 PNG data URL 与目标目录（空串 = 桌面）交给页面落盘，返回 `{ message }` |
| `onOpenExternal` | `(id: string) => void`：用外部播放器打开**当前 id**（页面实现 IINA 优先、回落系统默认）；不传则没有那颗按钮。tip 跟着设置里的应用名动态显示「用外部播放器打开（IINA）」。程序坞窗口在有文件页能力桥时也会拿到这颗按钮 |
| `onToggleBatch` | `(id: string) => void`：把当前这条加入 / 移出调用方的待拖拽区：只报「动一下」，方向按 id 查；不传则没有那颗按钮 |
| `batched` | 当前这条已在待拖拽区：那颗按钮亮成强调色、文案换成「从待拖拽区移出」 |
| `onPickDir` | 调系统目录选择框选截图存放目录；返回 `null` 表示取消。不传则路径没有「选择目录」 |
| `onRequestDelete` | `(id: string) => void`：请求删除当前视频：只应打开二次确认层；不传则没有删除按钮与 `Delete` 键 |
| `blocked` | 删除确认开着：整组快捷键与焦点陷阱交给确认层 |
| `externalApp` | 外部打开用的应用名（来自文件页设置的播放器列表）；只拼 tip，不参与打开动作 |
| `dockId` / `dockOrigin` | 程序坞条目的稳定 id 与来源；`dock` 恢复窗不继承页面里存着的网页全屏 |

弹窗**不知道**文件在哪、桌面在哪：路径、选择框与落盘都由调用方实现；组件只给「当前帧 + 目标目录」。
`onCapture` 的目录是用户偏好的原样字符串（空串表示默认），由调用方的落盘接口解释成真实路径。

## 实现约束

- `FreeVideo` 只认 `src` / `videoRef` / `nav` / `previewScale` / `actions` /
  `onAspectChange` / `onHoverFrameGrabberReady` / `tipDark` / `className`；视频元素引用交给弹窗复用（截图、空格播放、
  静音与方向键快进都读它），悬停帧的抓取函数由 `useFrameCapture` 收着，截图时先试它、拿不到再退回视频元素当前画面。
- **加入 / 移出待拖拽区**：排在外打开与设置之间那颗按钮，动的是调用方攒的那一批（文件页是
  `useDragPending`）——弹窗自己不存列表，翻篇 / 关窗都不动它；加进去以后面板**不浮出来**，
  靠调用方弹一条提示（面板比弹窗高一层，露出来会压住画面）。
- 控制栏右侧的业务操作收在 `VideoFooterActions`：顺序固定（选集 → 删除 → 截图 → 外部打开 →
  加入 / 移出待拖拽区 → 设置 → 网页全屏 → 整屏全屏）；喇叭在 `FreeVideo` 一侧、排在业务操作组之前；
  `VideoEpisodeMenu` 是选集点击弹层，开合状态自己管，只回传点选；
  条目列表走公共的 [`PreviewItemList`](../PreviewItemList/README.md)（与图片列表同一份）。
- 方向键快进直接改 `<video>` 的 `currentTime`，进度与时间文本由元素自己的 `timeupdate` 同步，
  不在弹窗里另存一份进度。
- 换片是 `key={id}` 重挂 `FreeVideo`——在同一个 `<video>` 上换 `src` 需要清理播放状态与进度，
  重挂比在 effect 里逐项复位更省心。
- 浏览器解不了的编码（mkv / avi / wmv 等常见）走 `error` 事件，舞台中央给一句人话，
  不静默停在黑屏；暂停时舞台中央**不放大播放键**，点画面或按空格都能继续播。
- 本组件内部的键盘监听为**零**：能按的键都在 `FreeModal`（播放、静音、翻篇、方向键、全屏、删除）里判，
  业务层不自己 `addEventListener('keydown')`。
- 视频流由 Vite 中间件 `GET /api/files/content` 按 Range 提供，截图由 `POST /api/files/capture`
  写进设置里的目录（默认桌面）；两者都只在开发模式存在（见 `docs/local-repo-data.md`）。
- `utils/seek.ts` 只算「挪到哪个时间点」，写回 `currentTime` 留在弹窗，
  避免挪动逻辑（含 NaN 时长兜底）在控制栏与方向键两处各写一遍。

### 收起到程序坞

快照存整个目录（多一张 `poster`）与当前条目，恢复后照常播放、翻篇与改播放偏好；
截图要写盘、外部打开要知道文件位置。文件页挂载时经 `PreviewDockActions` 把 `onCapture` /
`onOpenExternal` 等能力注入程序坞窗口；页面卸载后外部打开仍按快照里的 `externalApp` 走
`@/utils/open-file`，按钮不消失；`onCapture` 等页面能力清空，对应按钮与 `Enter` 截图不出现。整屏 / 网页全屏不再阻止收起：收起前先退出两种全屏，
恢复窗从普通尺寸出来；业务弹层或确认层开着时仍不可收起。契约见 `docs/dock.md`。
