# 切换计数浮标（`PreviewCounter`）

媒体预览翻篇时左上角那一下「3 / 12」。图片与视频两扇预览共用同一份，位置、字号、
停留时长与显隐动画都锁在这里，调用方只报数与切换序号。

## 它锁了什么

- **只报计数**：不显示文件标题，也不需要 header 或侧栏跟着出现——用户翻篇时只想知道「现在第几个」。
- **停留 1 秒**：浮出后 `SHOW_MS` 到点自己收起；每翻一次重新计时（`tick` 变就重来）。
- **显隐都带动画**：靠可见态类名上的过渡（透明度 + 从上方落位 + 轻微放大），
  所以组件常挂不卸——卸载就只剩出现、没有收起。
- **到点才收**：停留计时只写「哪个切换序号已过期」，可见与否由 `tick` 与它一比得出，
  不在 effect 里同步改可见态（会多一轮渲染）。
- **不吃指针**：`pointer-events: none`，压不住底下的画面与点击。

## props

| prop | 说明 |
| --- | --- |
| `index` | 当前位置，从 1 开始 |
| `total` | 总数 |
| `tick` | 切换序号：调用方每翻一篇加一；`0` 表示刚打开、还没翻过，此时不出现 |

## 调用方要做的

- 把「翻篇 / 侧栏点选」都收进一个自增 `tick` 的 handler，保证键盘、按钮、侧栏三种入口都会闪一下；
- 给它一个 `position: relative` 的父容器（预览区那一层），浮标自己 `position: absolute` 落在左上角。
