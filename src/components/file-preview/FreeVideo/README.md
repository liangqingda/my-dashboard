# 视频播放器（`FreeVideo`）

全站**唯一的视频播放器**：给一个地址就播，控制栏、加载态与报错态都在它里面。
它**不是预览容器**——不读路由、不弹窗、不做全屏、不列播放列表、不管截图落盘；
「在哪预览、怎么翻篇」由调用方组合（文件页的弹窗是 `VideoPreviewModal`）。选型见
`docs/ui-components.md`。

## 它锁了什么

- **控制栏**：`<video>` 的默认 `controls` 一律不用——原生控制栏样式跟着系统走，还自带一个
  「网页元素全屏」按钮，和站点自己的整屏交互不是一回事。播放 / 暂停、进度、时间全由
  `VideoControls` 给；喇叭与竖向音量条是独立的 `VideoVolumeControl`；循环、倍速不做（需要再加）。
  控制栏分上下两行：进度条独占上层，下层左侧前后 / 播放 / 时间，右侧是喇叭 + 调用方通过
  `actions` 塞进来的业务操作组。铺成整屏 / 网页全屏（`expanded`）后，播放键与前后箭头的**图标**
  放大一档（26 / 23px），按钮盒子与间距仍是原尺寸——大屏上图形不跟着放大就显得太小。
- **进度条悬停预览**：指针停在进度条上，上方浮出这一处的画面 + 时间（毛玻璃外框，
  宽取**视频画面实际显示区域**的 `previewScale`（默认 60%，可设 30%–90%，竖屏视频的黑边不算），
  高度按画面比例算并受舞台高度约束）。
  帧图由另一支 1px 隐藏探针 `<video>` 按指针时间**现抽**（0.5 秒一个缓存桶，抽过的位置直接复用，
  不预抽邻帧——探针一次只能 seek 一个点，预抽只会拖慢用户真正停下的那一帧）。
  时机是两道门槛：**在同一处停住 300ms 才浮出**（从画面往下移到控制栏会路过进度条，
  没这道门槛帧图就跟着闪一下；划过而不是停住的，计时随移动一直重排，干脆什么都不出现），
  浮出后落点与时间跟着指针走，**帧只在停稳 150ms 后换**（比浮出早 150ms 发请求，浮出时通常已经是画面）——
  一路扫过去不抽帧、不转圈，新帧回来前保留上一张，只有第一帧还没到的时候才转圈；
  帧与它的时间同源（换帧前时间标签可以先变，画面不会跑去一个它并不属于的秒数）。
  ±1px 的手抖不算移动，否则浮动与换帧的计时会被一直重排。
  轨道平时 4px（比 Mantine 默认的 8px 细一档），**只铺半透明底色**：控制栏这一层已经虚化了后面的视频，
  轨道再叠一层 `backdrop-filter` 只是重复采样、淡入时还会多抖一层，所以轨道不再自带玻璃。
  没 hover 时只有一层 20% 的薄底，已播放段也压到半透明，不抢画面；指针进到这条热区
  （上下各 4px 透明留白撑成 24px 高）就加粗到 12px，底色厚一档到 42% 并加 1px 内描边把边界框出来，
  已播放段一并提起——一眼能看出「现在正在这条上」，不再靠实色灰条与实色绿。
  **滑块跟着一起收放**：圆点画在滑块的 `::before` 上，没 hover 时只有 9px（4px 细轨道配 16px
  大圆点不合理），指针进来长回 16px。盒子本身不上色，仍是 `--slider-thumb-size`，所以命中区、
  0% / 100% 与轨道两端的对齐、挂在盒子里的数字浮标全都不动；触屏没有 hover，按住拖动的
  `data-dragging` 也直接给 16px。
  抽帧见 `hooks/use-video-frames/README.md`，浮出 / 换帧的时序见 `hooks/use-seek-preview/README.md`。
- **控制栏跟画面走**：与浮层 header 同一套节奏——打开即收起态，指针一动就浮出，
  静止 `CONTROLS_HIDE_DELAY`（1s）收起；指针停在控制栏上时始终显示。**暂停 / 播完也照常收起**
  （不再常驻），想操作就动一下指针，与视频预览的 header 一起浮出、一起收掉。
  控制栏**绝对定位压在舞台底部**，是盖在视频上的一层毛玻璃（半透明渐变 + 背景虚化），
  不占布局流；收起时只做淡出 + `pointer-events: none`，**不再随透明度一起下移**——位移会让虚化采样区
  每帧重算，控制栏出现的那一下就会闪。玻璃层另挂 `will-change: backdrop-filter` 与
  `backface-visibility: hidden`，提前把合成层留住。
  计时与「指针在不在控制栏上」都收在 `hooks/use-controls-visibility`，播放器不再自己挂 `setTimeout`。
  控制栏根节点带 `data-video-controls` 标记，对应 `constants.ts` 导出的 `VIDEO_CONTROLS_SELECTOR`：
  调用方判断「指针在这块区域里活动不算数」时用这个选择器（视频预览里就是不让浮层 header 跟着
  控制栏 hover 浮出），不要去挑 CSS module 的哈希类名。
- **点画面切播放，双击交给调用方**：单击画面切播放 / 暂停；传了 `onDoubleClick` 才接管双击——
  这时单击要等一个双击窗口（`@/hooks/useSingleOrDoubleClick`，300ms）再切播放，第二下到来就把
  这次播放 / 暂停作废，双击只执行调用方给的动作（视频预览里是切整屏全屏），**不闪播放态**。
  不传则点画面立刻切播放、双击什么都不做（逐次单击各按各的算）。
- **音量条不占横向宽度**：平时只有喇叭键，指针停在喇叭上才在它上方浮出**竖向**音量条
  （下 0 上 100，56px 高、正对喇叭中心线，容器留一段透明内边距当过桥，指针从喇叭移上去不会闪断）；
  tips 关掉，免得提示压住音量条；当前音量百分比贴在喇叭左侧，跟着音量条一起浮出（自带浮标靠右会被弹窗边缘裁掉）。
  喇叭图标按音量分三态（静音 / 低 / 高），见 `PlayerIcons/PlayerVolumeIcon`。
- **两颗箭头**：`nav` 给了才画，排在**播放键左右两侧**（左 → 播放 → 右），
  到头（`null`）的一侧置灰。控制栏归本组件，所以这两颗箭头也在这里，跟控制栏一起显隐。
  语义由调用方定：默认是翻篇，传 `previousLabel` / `nextLabel` 可以换成「快进 / 后退 N 秒」，
  播放器不判断这两颗箭头到底是哪种——视频预览里它们跟着「方向键去向」的设置切换。
  这两颗箭头的 tip 只亮 1s 就自己收掉（`tipDuration`），指针停着也不常挂，免得压住进度条。
- **状态**：`loading`（还没解出画面）给「正在读取视频…」、`error`（编码不支持）给一句人话、
  `buffering`（播放中卡住）给转圈；可播但暂停时**不在画面中央放大播放键**——点画面或按空格
  就能继续播，中央图标只会挡画面。
- **视频元素**：`disablePictureInPicture`、`playsInline`、`preload="auto"`；暂停 / 播完只改内部
  状态，不向外发事件。

## props

| prop | 说明 |
| --- | --- |
| `src` | 视频地址（通常是按 Range 提供流的接口 URL） |
| `videoRef` | 可选。外部要取当前帧、从键盘驱动播放时传；组件与内部 ref 合并后挂到 `<video>` |
| `nav` | 可选。`{ onPrevious, onNext, previousLabel?, nextLabel? }`，一端到头传 `null` 置灰；label 同时当 aria-label 与 tip；不传则控制栏没有这两颗箭头 |
| `actions` | 可选。控制栏下层右侧、喇叭之后的业务操作组（选集、截图、设置、全屏这类按钮与弹层）；播放器只负责排在最右，按钮归属全在调用方 |
| `overlayOpen` | 可选。是否有上层业务弹层（选集、设置这类）开着；开着时点画面只收弹层、不切播放，控制栏也按住不收起（面板是 portal，指针移进去就离开了播放器），默认 `false` |
| `onAspectChange` | 可选。解出元数据时回调一次片源宽高比（宽 / 高）；预览容器按它决定「框做多大」——视频预览弹窗据此把正文框收成同比例，画面正好填满、不留黑边 |
| `onCloseOverlay` | 可选。`overlayOpen` 时点画面触发：关闭当前开着的业务弹层 |
| `onDoubleClick` | 可选。双击画面的动作（视频预览里是切整屏全屏）；给了才区分单击 / 双击，单击切播放延后一个双击窗口、第二下到来就作废，双击不动播放态 |
| `expanded` | 可选。画面是否已铺开（整屏全屏 / 网页全屏）：给 `true` 时播放键与前后箭头的图标放大一档，按钮盒子与间距不变；默认 `false` |
| `previewScale` | 可选。悬停预览框宽占视频画面宽度的比例，0.3–0.9，不传按 0.6；超出范围按边界夹住 |
| `onHoverFrameGrabberReady` | 可选。浮层正显示某帧时回调一个「取这一帧」的函数（异步，给 PNG data URL），收起时回调 `null`；探针已在那一帧上就按视频原始尺寸重画，不在就补 seek 过去再画（此时调用方要等解码），seek 也失败才退回浮层里的缩略帧 |
| `className` | 可选。只用来补外部布局（撑满父容器之类） |
| `tipDark` | 可选。控制栏按钮与滑杆浮标固定深底浅字、不随主题反转；媒体画面上的提示用 |

## 边界

- **换片**由调用方 `key` 重挂（一个视频一个实例）；本组件不监听 `src` 变化复位状态，
  否则同一个实例上换源还要自己清进度、音量与状态。
- **全屏、header、侧栏、截图**都不在这里：需要的是预览容器，不是播放器。
- 键盘监听为**零**：空格切播放这类键位归外壳（弹窗里是 `FreeModal` 的 `media`），
  本组件只暴露可点的控制。外部若要键盘驱动，读 `videoRef` 自己调 `play()` / `pause()`。
- 浏览器解不了的编码（mkv / avi / wmv 等常见）走 `error` 事件，不静默停在黑屏。
- **抽帧探针**：播放器里另有第二支 1px 隐藏 `<video>`（同 `src`、`preload="auto"`、
  不接指针），按 hover 时间 seek 取帧；它不是第二个播放器，不参与布局、不进控制栏。
  预览框尺寸随「舞台 + `previewScale` + 视频画面比例」变化（见 `utils/preview-size.ts`），缩窗或改设置后
  帧图尺寸与取帧分辨率一起重算，帧缓存随之清空重来。
