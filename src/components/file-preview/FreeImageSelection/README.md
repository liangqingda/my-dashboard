# FreeImageSelection

全站唯一的**图片选框**：叠在图片盒子上的一层可拖矩形，拖框平移、拖八个手柄改尺寸，
只回传「相对图片的比例矩形」。它不裁剪、不编码、不写盘，也不认识文件、保存方式这些业务。

和 `FreeImage` 是一对：舞台量好自己的图片盒子交给它（`overlay` 回调的 `box`），
它按同一个盒子摆选框，所以窗口缩放、进出全屏、切 `fill` 时选框都跟着画面走。

## 它锁了什么

- **选框形态**：1px 浅色描边 + `100vmax` 外阴影当遮罩（选框外压暗，舞台自己 `overflow: hidden`），
  四角 + 四边共 8 个手柄（12px 白块、方向对应的 `resize` 光标），选框下方一颗提示胶囊。
- **拖拽口径**：Pointer Events + 指针捕获，手指与鼠标同一套；拖出画面不断，松手在画面外也能收尾。
  位移按「按下那一刻的选框 + 本次总位移」现算（不逐帧累加，抖动不会攒误差）。
- **最小尺寸**：32px；换算成比例时 `min(1, 32 / box.width)`，极窄的图最多按整幅算。
- **只认比例**：入参 / 回传都是 0–1 的 `SelectionRect`（`x / y / width / height`），
  按 `box` 的布局尺寸换算显示位置；不看 `getBoundingClientRect`，`transform: scale()` 不会把坐标算歪。
- **盒子由外面给**：自己不量 DOM、不挂 `ResizeObserver`；`box` 宽或高为 0 时整块不渲染。

## props

- `box`：图片在舞台里的布局矩形（px，相对舞台左上角）——由 `FreeImage` 的 `overlay` 回调传入；
- `rect`：当前选框（比例 0–1，受控）；
- `onChange`：拖动回传新选框；
- `hint`：选框下方提示文案，默认「拖动选框调整裁剪范围」。

## 不该放进来

- 裁剪的会话与落盘（进入 / 取消、保存方式、canvas 编码、写文件、成功提示）：
  归 `ImagePreviewModal` 的 `hooks/use-image-crop`；
- 缩放 / 平移与加载 / 失败态：归 `FreeImage`；
- 工具栏、图片列表、删除、墙纸：归弹窗。
