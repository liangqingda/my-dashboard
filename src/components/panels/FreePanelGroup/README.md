# 弹层面板分组（`FreePanelGroup`）

弹层设置面板里的一组同类设置：**浅底色圆角块 + 组标题 + 组内容**。
设置项一多就按主题分块，块与块之间不描边、只用底色区分——同一个弹层里所有分组长得一样。

| 项 | 约定 |
| --- | --- |
| 结构 | `<section>` 一块：`padding: 10px 12px`、圆角 10、底色 `var(--app-surface-hover)`，块内标题 + 内容上下排 |
| `layout` | `'fields'`（默认）：内容横向排、放不下自动换行（间距 `10px 12px`），配 `FreePanelField` 使用；`'stack'`：内容竖向排（间距 6px），给快捷键清单这类非字段内容 |
| props | `title`、`children`、`layout` |
| 不负责 | 组内放什么字段、文案、顺序 |

## 它锁住什么

「弹层设置分组」全站只有一种形态：底色、圆角、内边距、组标题的字号与字重、组内间距。
业务侧只写标题与内容，不另写 `section` + 自定义底色（`Files` 设置面板与视频设置面板都用它）。
