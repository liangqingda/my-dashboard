# 弹层面板字段（`FreePanelField`）

设置面板里的一个字段：**上面一行小字标题（可带当前值），下面挂控件**。
多个字段横向排、放不下自动换行；需要占满整行的（滑块、路径行）传 `wide`。

| 项 | 约定 |
| --- | --- |
| 结构 | 竖向容器：标题行（`Text` 灰字 `0.72rem`）+ 控件；`value` 与标题同一行靠右显示 |
| 尺寸 | 默认 `flex: 1 1 148px`，同一行能排几个由面板宽度决定；`wide` 时 `flex-basis: 100%` |
| props | `label`、`value`（可选，标题行右侧的当前值）、`wide`、`children` |
| 不负责 | 控件是什么（分段控件 / 下拉 / 输入 / 滑块 / 路径行由调用方给） |

## 它锁住什么

「弹层设置里的字段」全站只有一种形态：标题的字号、颜色与控件之间的 6px 间距、
字段的 flex 基准与换行规则。业务侧不再各自写 `label` + `marginBottom` 这类样式。
