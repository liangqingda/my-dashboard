# EntryTileActions

瓦片右上角浮出的操作按钮组：文件夹 / 文件是重命名 + 删除（图片另加「设为桌面墙纸」），应用只有卸载一项。

## 职责边界

- 用 `FreeIconAction`（`sm` 档 + 16px 图标，与标题栏同档）；整组坐在一层玻璃底片上，缩略图有亮有暗，图标直接压上去会飘，垫一层随主题变的半透明底片才稳。
- 显隐由瓦片外壳 hover 控制，本组件只负责按钮与定位排布；表格视图传自己的定位类，让按钮常态可见。

## 坑

- 按钮不挂悬停提示（`tooltip="none"`）：压在缩略图上，浮出的 tip 比按钮还抢眼；含义留在 `aria-label` 给读屏。
- 点击各自吞掉冒泡，避免触发瓦片本体的打开行为；新增按钮别忘了 `stopPropagation`。
- 组件已 `memo`：回调需稳定引用。
