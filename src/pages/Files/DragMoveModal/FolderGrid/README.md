# FolderGrid

拖拽移动弹窗里的**文件夹落点网格**：一格一个子文件夹，既是放置目标、也是「点进去」的按钮。
入参见 `types.ts`，动画与禁用口径见 `index.scss` 注释。

## 三种态

| 态 | 触发 | 表现 |
| --- | --- | --- |
| 平常 | 指针停在格子上 | 描边与底变强调色、图标变色、往下打一层淡阴影（滚动视口会裁上沿，所以不往上抬） |
| 拖拽经过 | 拖着东西压在格子上 | 强调色底 + **后半秒才出现**的倒计时条（整段 1 秒，前 0.5 秒不画进度）；满一秒先弹一下再进这一层 |
| 禁用 | **手上的条目本来就全在这一格里** | 虚线边 + 压暗、`cursor: not-allowed`；指针压上来时（`blockedOn`）回亮一点，并在格子里补一句「本来就在这个文件夹里」；不起进入计时、不画倒计时 |

禁用只在**拖拽中**成立（`dragActive`）：平常悬停照样能点进去，那只是浏览这一层。

## 为什么禁用要自己判断

落点瓦片由会话给（`stripSelf` 只摘掉「被拖的那些文件夹自己」），
但「条目本来就在这一格」是另一回事：移进去等于没动。所以这里按 `parentDirOf` 判
`allInsideDir(entries, folder.path)`——**全部**在里面才是禁用；
只有一部分在里面时格子仍然可放，松手后由会话 `splitByParent` 剔出那几条（它们留在待拖拽区）并提示。

## 刚搬进来的那几条

弹窗没关时（只搬走了一部分），搬进的那个文件夹在名字下面**平铺本次搬进去的条目**
（`landed` 里 `targetDir === folder.path` 的那些）：图片 / 视频摆缩略图，其它摆分类图标，右边一行文件名。
点某一条就把它搬回原目录（`onRetract`），并回到待拖拽区；搬走的那一条在格子里留成虚线虚位，
看得出刚才这儿还有一条。开始新一次会话时这份记录清空。

格子因此拆成「外层 `div`（放置目标 + 禁用态）」与「内层按钮（图标 + 名字，点进这一层）」：
搬进来的行本身也是可点的，不能再嵌在格子的按钮里。
