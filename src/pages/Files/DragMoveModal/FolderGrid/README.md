# FolderGrid

拖拽移动弹窗里的**文件夹落点网格**：一格一个子文件夹，既是放置目标、也是「点进去」的按钮。
指针停在格子上**不会自动进入**（换层只认点击），拖拽中的 `hoverPath` 与禁用落点都由本组件自己记。
入参见 `types.ts`，动画与禁用口径见 `index.scss` 注释。

## 三种态

| 态 | 触发 | 表现 |
| --- | --- | --- |
| 平常 | 指针停在格子上 | 描边与底变强调色、图标变色、往下打一层淡阴影（滚动视口会裁上沿，所以不往上抬） |
| 拖拽经过 | 拖着东西压在格子上 | 换成强调色底（说明「这里可以放」）；**停在格子上不会自动进入**，换层只认点击 |
| 禁用 | **手上的条目本来就全在这一格里** | 虚线边 + 压暗、`cursor: not-allowed`；指针压上来时（`blockedOn`）回亮一点，并在格子里补一句「本来就在这个文件夹里」；不进高亮 |

| 正在搬进这一格 | 松手后真的在搬 | 与列表页 `FolderTile` 同一套：强调描边 + 微抬起 + 底边一条进度条，计数位改写成「正在移动 x / y」 |

禁用只在**拖拽中**成立（`dragActive`）：平常悬停照样能点进去，那只是浏览这一层。

## 为什么禁用要自己判断

落点瓦片由会话给（`stripSelf` 只摘掉「被拖的那些文件夹自己」），
但「条目本来就在这一格」是另一回事：移进去等于没动。所以这里按 `parentDirOf` 判
`allInsideDir(entries, folder.path)`——**全部**在里面才是禁用；
只有一部分在里面时格子仍然可放，松手后由会话 `splitByParent` 剔出那几条（它们留在待拖拽区）并提示。
