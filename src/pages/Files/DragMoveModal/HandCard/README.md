# HandCard

拖拽移动弹窗里的待拖拽区：被拖的这批条目**网格平铺**在这里（整块占满一行宽度、能摆几条就摆几条，
横竖间距 12px），可以逐条再拖起、也可以整批拖。

浏览器在 `drop` / 松手那一刻就结束了整次拖拽，而全屏弹窗盖住了底层列表——
所以必须把条目留在弹窗里让人重新拿起，这块就是那个落脚处。

## 结构

- 外层 `.tray`：整块 `draggable`（拖它的空白处 = 整批搬），`data-hand-blank` 给样式认；
- 里面 `.chips` 是 `grid`（`repeat(auto-fill, minmax(168px, 1fr))`、`gap: 12px`），每条 `.chip`：抓手图标 + 按类型取的图标（`utils/entry-icon.ts`）+ 名字；
  每个 chip 自己 `draggable` 且 `stopPropagation`（拖某一条只搬它，别的留在页面侧栏的待拖拽区）。

## 交互

- **只有一条且是图片 / 视频时**那一行的图标才可点：点它不拖，打开内置预览（`onPreview`）；
- 名字的 hover 提示一律 `disabled`——这里本来就是拖拽态，不该冒 tooltip；
- 实线边 = 正在拖（`live`）；虚线边 + 一圈呼吸光 = 已经放回手里（`idle`），
  让人一眼看出「这是待拖拽的条目」；`prefers-reduced-motion` 下呼吸光只留静态虚线边；
- 底部一句随条数与状态变的提示（`handHint`）：多条讲「拖某一条只搬它，拖这块空白处搬这 N 项」，
  单条讲「放到目标文件夹上松手即移入」/ 已放回手里时讲「按住这条再拖一次」。
