# HandCard

拖拽移动弹窗里的「手持卡片」：被拖的条目本体摆在弹窗里，可以再次拖起。

浏览器在 `drop` / 松手那一刻就结束了整次拖拽，而全屏弹窗盖住了底层列表——
所以必须把条目留在弹窗里让人重新拿起，这张卡片就是那个「手」。

- 图标按条目类型取（`utils/entry-icon.ts`）；**多于一条时叠三层**、左上角红点标数量，
  名字变「第一项 等 N 项」，拖起时 `dataTransfer` 写全部路径。
- **只有一条且是图片 / 视频时**图标才可点：点它不拖，打开内置预览（`onPreview`）。
- 实线边 = 正在拖（`live`）；虚线边 + 一圈呼吸光 = 已经放回手里（`idle`），
  让人一眼看出「这是待拖拽的条目」。
- `prefers-reduced-motion` 下呼吸光只留静态虚线边。
