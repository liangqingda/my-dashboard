# DragMoveModal

拖拽移动弹窗：文件页列表里任一条目（网格瓦片 / 表格行）被拖起时自动打开，占满整屏挑落点。
状态与动作在 `hooks/use-drag-move`，这个组件只负责呈现；新建文件夹与预览这两件需要页面上下文的事，
由页面把动作传进来。

## 它呈现什么

**全屏弹窗**（`fullscreen={{ active: true, showToggle: false }}`，header 只有标题、一颗新建文件夹按钮与关闭按钮）。

1. **当前路径**：复用目录页的面包屑 `DirBreadcrumb`（按家目录 / 外接卷 / 本机换根图标），
   每段可点，点了就换到那一层——换层只走这一条路。
2. **手持卡片**：被拖的条目本体——图标 + 名字 +「拖拽中 / 待拖拽」徽章，拖拽在飞时旁边跟一句操作提示。
   - 图标按条目类型取：文件夹是文件夹图标，文件取 `CATEGORY_ICONS[category]`（视频 / 图片 / PDF / Markdown / 其它各一枚）；
   - **图片 / 视频的图标可点**，点开内置预览（`onPreview`，设置里选了「外部应用」也不影响这里），
     其它分类只展示图标、不挂点击；
   - 卡片本身 `draggable`，放回手里以后还能再拖起（`onDragStart` 里写 `dataTransfer` 并调 `beginDrag`）。
3. **这一层的子文件夹**：大瓦片网格按宽度自动折列；加载中 / 读失败 / 没有子文件夹各有占位句。
   瓦片可点（不拖的时候点一下就进去），拖拽经过时按 `hoverPath` 亮倒计时条、按 `springPath` 播弹起动画。
   被拖的那个文件夹不在列表里（`stripSelf` 过滤，拖文件夹时不能落进自己）。
   拖拽悬在**空白处**（不在任何瓦片上）时，整块落点区换成实线强调边 + 强调底，
   顶上浮一枚「松开即移入当前文件夹」的提示；**这一层正好是条目原本所在的目录**时提示压成灰的
   「它本来就在这个文件夹里，松开不做移动」，颜色一并退掉——同一个手势，这里不会发生移动。

## 新建文件夹

header 右侧那颗按钮（`FreeIconAction`）走页面的 `createEntryIn(view.path)`：
在**当前这一层**落一个默认名文件夹、刷新列表、随即弹改名弹窗（与标题栏那颗按钮同一套流程）。
改名提交后 `useDragMove.refreshView()` 让这一层就地重读，不用退出重进。

## 放置判定

| 松手 / 操作位置 | 结果 |
| --- | --- |
| 某个文件夹上（未满 0.5 秒） | 关窗并移进该文件夹，成功后播落位音效 |
| 同一个文件夹上停留满 0.5 秒 | 先弹起它（220ms），再进入它、列出它的子文件夹；**不移动** |
| 落点区的空白处（不是条目原目录） | 移进当前这一层并播音效 |
| 落点区的空白处（就是条目原目录） | 不做任何移动，条目回到手里，弹窗不关 |
| 点某个文件夹瓦片（没在拖） | 进入它，换层继续挑 |
| 关闭按钮 / Esc | 取消整次移动，不做任何写操作 |

- 「松手即移入」与「停留即进入」互斥，靠倒计时条区分：条填满就换层，倒计时时长由
  `SPRING_HOVER_MS` 经内联 `animationDuration` 给，SCSS 只留动画名与时序。
- **只有成功移动才关窗**。其余一切松手都回到「手持态」（`handed`）：浏览器在 `drop` 那一刻
  就结束了整次拖拽，`dragend` 必到，而全屏弹窗盖住了底层列表，所以必须把条目留在弹窗里
  让人再拖一次——这也是手持卡片存在的原因。
- 同一会话里读过的目录按路径缓存，来回进出同一层不重复扫盘；最外层直接用页面已有的列表。

## 落地细节

`utils.ts` 里两个拖拽事件小工具：`acceptMove`（`preventDefault` + `dropEffect = 'move'`，
不拦就没有 `drop`）、`leaveOutside`（父子元素间移动也会触发 `dragleave`，只认真离开整块的那次）。
`closeOnClickOutside={false}`（拖拽指针扫过遮罩不该关窗）、`closeOnSpace={false}`（空格留给瓦片按钮）、
`trapFocus={false}`（拖拽中打开的弹窗不需要焦点陷阱）。

## 音效

`utils/move-sound.ts` 用 WebAudio 现场合成一声短促的「落定」，不带音频素材。
只在移动**提交成功**后播；没有 WebAudio 或被音频策略拦下时静默跳过。

## props

| 字段 | 用途 |
| --- | --- |
| `dragMove` | `ReturnType<typeof useDragMove>`：开合、当前层、悬停 / 弹起态与各落点动作 |
| `onCreateFolder(dir)` | 在给定目录新建文件夹（页面接到 `createEntryIn`） |
| `onPreview(file)` | 用内置预览打开图片 / 视频（页面按分类分流到图片 / 视频预览） |
