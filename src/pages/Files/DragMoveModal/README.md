# DragMoveModal

拖拽移动弹窗：文件页列表里任一条目（网格瓦片 / 表格行）被拖起时自动打开，替代「只能拖到隔壁文件夹」的一步到位。
状态与动作在页面层 `hooks/useDragMove`，这个组件只负责呈现。

## 它呈现什么

三段纵排，取消区固定最底、不随文件夹列表滚动：

1. **当前位置**：目录栈拼成一行的路径（从拖拽起点到当前层），加一句操作提示；
2. **文件夹落点**：当前层有哪些子文件夹，按瓦片宽度自动折列；加载中 / 读失败 / 没有子文件夹各有自己的占位句；
3. **取消区**：斜纹底纹 + 虚线边的整条横带，文案随层数变化（`松手取消本次移动` / `松手回到最外层`）。

header 只有标题（`移动「条目名」`）与组件库内建关闭按钮，不放操作组。

## 放置判定

| 松手位置 | 结果 |
| --- | --- |
| 某个文件夹上（未满 1.5 秒） | 关窗并移进该文件夹，移动成功后播放落位音效 |
| 某个文件夹上停留满 1.5 秒 | 先弹起该文件夹（220ms），再进入它、列出它的子文件夹；**不移动** |
| 文件夹列表的空白处 | 移进当前这一层并播落位音效（已在起点层则是原地，等同取消并关窗） |
| 底部取消区（已在起点层） | 取消整次移动，关闭 |
| 底部取消区（已在更深的层） | 退回最外层（拖拽起点那一层），弹窗**不关闭** |
| 关闭按钮 / Esc / 拖拽自行结束 | 取消整次移动，不做任何写操作 |

- 「松手即移动」与「停留即进入」是两条互斥的判定，靠 1.5 秒的倒计时条区分：条填满就换层。
- 同一会话里读过盘的目录按路径缓存，来回进出同一层不重复扫描；最外层直接用页面已有的列表。
- 移动失败（同名冲突、移进自身后代）由 `useEntryActions` 弹提示，弹窗已经关闭、条目留在原位。

## 音效

`utils/move-sound.ts` 用 WebAudio 现场合成一声短促的「落定」，不带任何音频素材。
只在移动**提交成功**后播；浏览器没有 WebAudio 或音频策略拦下时静默跳过。

## props

只有一组：`dragMove`（`ReturnType<typeof useDragMove>`）——包括 `session`（开合）、`levels`（目录栈）、
`loading` / `error`、`hoverPath` / `springPath`（倒计时与弹起态），以及 `close`、`dropOnFolder`、
`dropOnBlank`、`dropOnCancelZone`、`hoverFolder`、`leaveFolder`。

`trapFocus={false}`：弹窗在拖拽过程中打开，不需要键盘焦点陷阱；`closeOnClickOutside={false}`
是避免拖拽指针扫过遮罩时把弹窗关掉——真正收起只认关闭按钮、Esc 与拖拽结束。
