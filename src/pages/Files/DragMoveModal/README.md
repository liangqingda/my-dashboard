# DragMoveModal

拖拽移动弹窗：文件页列表里任一条目（网格瓦片 / 表格行）被拖起时自动打开，替代「只能拖到隔壁文件夹」的一步到位。
状态与动作在页面层 `hooks/useDragMove`，这个组件只负责呈现。

## 它呈现什么

**全屏弹窗**（`fullscreen={{ active: true, showToggle: false }}`，header 只有标题与关闭按钮）。
正文竖排三段，文件夹列表吃掉剩余高度，底部两个停靠区永远贴底：

1. **当前位置**：目录栈拼成一行的路径（从拖拽起点到当前层），下一句是操作提示；
2. **文件夹落点**：当前层有哪些子文件夹，大瓦片网格按宽度自动折列；加载中 / 读失败 / 没有子文件夹各有自己的占位句。
   被拖的那个文件夹不在列表里（由 `stripSelf` 过滤）。
3. **底部停靠区**：左侧「回到上一层」，右侧「取消」。
   - 左：指针停 0.5 秒自动退一层；已在最外层时压淡，写「已经在最外层」；
   - 右：斜纹底纹 + 虚线边，文案随层数变化（`取消本次移动` / `取消 · 回到最外层`）。

## 放置判定

| 松手 / 操作位置 | 结果 |
| --- | --- |
| 某个文件夹上（未满 1.5 秒） | 关窗并移进该文件夹，移动成功后播放落位音效 |
| 某个文件夹上停留满 1.5 秒 | 先弹起该文件夹（220ms），再进入它、列出它的子文件夹；**不移动** |
| 文件夹列表的空白处 | 移进当前这一层并播落位音效（已在起点层则是原地，等同取消并关窗） |
| 左下角「上一层」停留满 0.5 秒 | 退一层，继续挑（不松手） |
| 左下角「上一层」松手 / 已在最外层 | 退一层并留窗；最外层时等同放弃并关窗 |
| 右下角取消区（已在起点层） | 取消整次移动，关闭 |
| 右下角取消区（已在更深的层） | 退回最外层（拖拽起点那一层），弹窗**不关闭** |
| 关闭按钮 / Esc / 拖拽自行结束 | 取消整次移动，不做任何写操作 |

- 「松手即移动」与「停留即进入」是两条互斥的判定，靠 1.5 秒的倒计时条区分：条填满就换层。
- 同一会话里读过盘的目录按路径缓存，来回进出同一层不重复扫描；最外层直接用页面已有的列表。
- 移动失败（同名冲突、移进自身后代）由 `useEntryActions` 弹提示，弹窗已经关闭、条目留在原位。

## 松手之后还开着的时候

取消区 / 上一层让目录栈退回去时，弹窗按规则留着。但浏览器在松手那一刻就结束了整次拖拽，
而全屏弹窗又把底下的列表盖住了，所以这时只能点选：`dragEnded` 为真时，文件夹瓦片挂 `onClick`
（点了即移入），提示语换成「拖拽已经在松手时结束：点文件夹即可移入…」，右下角取消区点了即关窗。
`dragEnded` 为假（拖拽进行中）时这些点击一律不挂，免得误触。

## 音效

`utils/move-sound.ts` 用 WebAudio 现场合成一声短促的「落定」，不带任何音频素材。
只在移动**提交成功**后播；浏览器没有 WebAudio 或音频策略拦下时静默跳过。

## props

只有一组：`dragMove`（`ReturnType<typeof useDragMove>`）——包括 `session`（开合）、`levels`（目录栈）、
`loading` / `error`、`hoverPath` / `springPath` / `parentHovering`（倒计时与点亮）、`dragEnded`（松手后留窗），
以及 `close`、`dropOnFolder`、`dropOnBlank`、`dropOnCancelZone`、`dropOnParentZone`、
`hoverFolder`、`leaveFolder`、`hoverParentZone`、`leaveParentZone`。

`trapFocus={false}`：弹窗在拖拽过程中打开，不需要键盘焦点陷阱；`closeOnClickOutside={false}`
是避免拖拽指针扫过遮罩时把弹窗关掉——真正收起只认关闭按钮、Esc 与拖拽结束。
`closeOnSpace={false}`：正文里的文件夹瓦片是按钮，空格要留给它们自己的激活，不能一按就关窗。
