# DragMoveModal

拖拽移动弹窗：文件页列表里任一条目（网格瓦片 / 表格行）被拖起时自动打开，
占满整屏挑落点。状态与动作在 `hooks/use-drag-move`，这个组件只负责呈现。

## 它呈现什么

**全屏弹窗**（`fullscreen={{ active: true, showToggle: false }}`，header 只有标题与关闭按钮），
正文四段竖排，文件夹列表吃掉剩余高度，底部两个停靠区永远贴底：

1. **当前路径**：复用目录页的面包屑 `DirBreadcrumb`（按家目录 / 外接卷 / 本机换根图标），
   每段可点，点了就换到那一层；
2. **手持卡片**：被拖的条目本体——图标 + 名字 +「拖拽中 / 待拖拽」徽章，
   旁边一句提示随状态换。卡片本身 `draggable`，放回手里以后还能再拖起（`onDragStart` 里
   写 `dataTransfer` 并调 `beginDrag`）；
3. **这一层的子文件夹**：大瓦片网格按宽度自动折列；加载中 / 读失败 / 没有子文件夹各有占位句。
   瓦片可点（不拖的时候点一下就进去），拖拽经过时按 `hoverPath` 亮倒计时条、按 `springPath` 播弹起动画。
   被拖的那个文件夹不在列表里（`stripSelf` 过滤，拖文件夹时不能落进自己）。
4. **底部停靠区**：左侧「回到上一层」，右侧「回到最外层」。
   - 左：指针停 0.5 秒自动退一层，点一下也退一层；到根时压淡，写「没有上一层」；
   - 右：斜纹底纹 + 虚线边，指针经过加深；到根时压淡，写「已经在最外层」。

## 「最外层」是根

不是拖拽起点，而是 `rootPath` 认定的根：家目录 `/Users/<user>`、外接卷 `/Volumes/<x>`、
其余回落到 `/`（与目录页面包屑同一口径）。所以在 `~/Documents` 里拖起、层层深入后按右侧，
是一路退到家目录，不是退到 `~/Documents`。

## 放置判定

| 松手 / 操作位置 | 结果 |
| --- | --- |
| 某个文件夹上（未满 0.5 秒） | 关窗并移进该文件夹，成功后播落位音效 |
| 同一个文件夹上停留满 0.5 秒 | 先弹起它（220ms），再进入它、列出它的子文件夹；**不移动** |
| 文件夹列表的空白处 | 移进当前这一层并播音效；当前层就是条目原目录（原地）时只放回手里 |
| 点某个文件夹瓦片（没在拖） | 进入它，换层继续挑 |
| 左停靠区停满 0.5 秒 / 点一下 / 松手 | 退一层，条目留在手里 |
| 右停靠区松手 / 点一下 | 一路退到根，条目留在手里 |
| 面包屑、卡片行、停靠区之外的空隙 | 什么都不做，条目留在手里 |
| 关闭按钮 / Esc | 取消整次移动，不做任何写操作 |

- 「松手即移入」与「停留即进入」互斥，靠倒计时条区分：条填满就换层，倒计时时长由
  `SPRING_HOVER_MS` 经内联 `animationDuration` 给，SCSS 只留动画名与时序。
- **只有成功移动才关窗**。其余一切松手都回到「手持态」（`handed`）：浏览器在 `drop` 那一刻
  就结束了整次拖拽，`dragend` 必到，而全屏弹窗盖住了底层列表，所以必须把条目留在弹窗里
  让人再拖一次——这也是手持卡片存在的原因。
- 同一会话里读过的目录按路径缓存，来回进出同一层不重复扫盘；最外层直接用页面已有的列表。
- 移动失败（同名冲突、移进自身后代）由 `useEntryActions` 弹提示，弹窗此时已关，条目留在原位。

## 落地细节

`utils.ts` 里两个拖拽事件小工具：`acceptMove`（`preventDefault` + `dropEffect = 'move'`，
不拦就没有 `drop`）、`isInsideSelf`（父子元素间移动也会触发 `dragleave`，只认真离开整块的那次）。
`closeOnClickOutside={false}`（拖拽指针扫过遮罩不该关窗）、`closeOnSpace={false}`（空格留给瓦片按钮）、
`trapFocus={false}`（拖拽中打开的弹窗不需要焦点陷阱）。

## 音效

`utils/move-sound.ts` 用 WebAudio 现场合成一声短促的「落定」，不带音频素材。
只在移动**提交成功**后播；没有 WebAudio 或被音频策略拦下时静默跳过。

## props

只有一组：`dragMove`（`ReturnType<typeof useDragMove>`）。
动作与状态清单见 `../hooks/use-drag-move/README.md`。
