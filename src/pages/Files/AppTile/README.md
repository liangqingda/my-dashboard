# AppTile

网格里的一条**应用包**瓦片：图标在上、应用名在下，点瓦片交给系统打开，hover 浮卸载入口。

## 职责边界

- 应用包按一条应用展示（真实图标 + 卸载入口），**不进待拖拽区、不可拖拽移动**——移动 `.app` 会破坏系统登记。
- 不参与分组多选与落点判定；打开 / 卸载两个动作之外的状态都不在这一层。

## Props 要点

| 字段 | 口径 |
| --- | --- |
| `app` | 应用摘要（图标、名称、路径） |
| `launching` | 正在启动：按钮暂不可点，副文案换成「正在打开…」 |
| `onOpen` | 点瓦片交给系统打开这个应用 |
| `onRequestUninstall` | 请求卸载（先弹二次确认并列出残留；系统自带应用不会走到这里） |
| `tipOff` / `veilOpacity` | 拖拽中不弹名称 tooltip；遮罩透明度，与其它瓦片同一档设置 |

## 坑

- 名称最多两行，超出**尾部省略**、hover 给全量（走 `FreeTruncatedText` 的 `ellipsis="end"`）：瓦片宽度会在静止状态下变，尾部省略按当下宽度现量，调小后不会涨成三、四行。
- hover 时应用图标放大 6%，过渡 180ms，与文件 / 文件夹瓦片的图源同一档。
- 应用瓦片没有改名 / 删除 / 设墙纸入口；新增应用类动作先确认是不是只属于这一类条目。
- 组件已 `memo`：回调需稳定引用，否则 memo 被新引用击穿。
