# FilesLockGate

文件页安全锁：开启后进入页面前先问一次密码，对了才放行；这扇窗**关不掉**——没有关闭按钮，Esc / 遮罩 / 空格都不响应，只有「返回」与「进入」两个出口。

## 职责边界

- 只做密码逐字比对与放行；密码存哪、开关怎么开在 `useFilesSettings` / `useFilesLock`。
- 对不上就把输入框标红、不改输入内容，方便原地改一个字再试；错误提示只在这扇窗里出现，不弹全局通知。
- 本次停留输对过一次即放行，会话内有效，离开页面重新进再问一次。

## 边界（必须写明）

- 密码原样存 localStorage，**不做哈希、不做强度 / 格式校验**；这是本机单机防君子性质，不是加密存储，别在 UI 或文档上承诺安全强度。
- 想改密码走设置面板；关掉锁开关即不再拦截。
