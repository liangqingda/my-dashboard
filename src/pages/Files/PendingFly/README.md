# PendingFly

「条目在列表与待拖拽区之间挪动」的那一下动画，两个方向共用一套：
- **移入**：点选（`⌘` / `Shift` + 点击，或待拖拽区非空后的普通点击）把瓦片收进侧栏；
- **移出**：点待拖拽区里的某一格（或在列表里再点一次已选中的条目）让它飞回原位。

## 怎么做

- 起点：`flight.from`（移入是那张瓦片的矩形，移出是待拖拽区那一格的矩形），由 `useDragPending` 量好带进来；
- 终点：移入遍历 `[data-pending-chip]` 找**它真正落脚的那一格**，移出遍历 `[data-entry-path]` 找**它那张瓦片**；
  命不中（侧栏收起 / 该条已不在采光内）就原地淡掉；
- 飞行块按**列表里那一张瓦片**的尺寸建（两个方向都取瓦片：移入时它是起点、移出时它是终点），
  空中飞的「真身」是 `tileOf(entry.path)` 的原样深拷贝 `cloneNode(true)`——视频帧、文件名、边距、
  悬停按钮全在，只有尺寸在变；拷贝只清掉 `id` / `tabindex`、压成绝对定位并停用指针。
- 轨迹一条 `FLY_MS = 560` 播完，两个方向互为镜像：
  - **移出（回列表）**：图标起步（`scale(0.3)`、轻微上浮）→ 三成时换真身（此时还小，看不出拼接）
    → 飞到落点上方长到 **90%** 停一下 → 补到 100% 并往下沉 3px 落定；
  - **移入（收进待拖拽区）**：真身起步、正好盖住原位（`scale(1)`）→ 抬起 6px → 收到 **90%** 停一下
    → 一路缩到很小时把真身换回**图标**（与回来那趟对称）→ 落进那一格，末段按「chip / 瓦片」等比缩并淡出交还 chip。
    原件**不藏不换**、一直留在原位：飞行块就是它的整块拷贝，起步时正好盖住它、之后缩小着离开，原位那项不会闪。
    落点那一格在飞行期间是「空位」（`landingPath`，虚线框 + 透明内容），飞行落定后由那一格自己的内容层
    从 `scale 0.5` 长到 1——落地看到的是拖拽区的样式在长大，不是列表样式在渐变。
  缓动 `cubic-bezier(0.32, 0.72, 0.24, 1)`、`fill: 'forwards'`，`onfinish` 回调 `clearFlight` 收掉这一层。

## 兜底

- 系统开了「减少动态」（`prefers-reduced-motion`）→ 不做位移，直接 `onDone`；
- DOM 上找不到终点（侧栏收起、那一格已不在）→ 就地淡掉后 `onDone`，不乱飞；
- 回调放 `doneRef`（在 effect 里同步），effect 只依赖 `fly`：父级每次渲染的新函数不会让动画重启动。
