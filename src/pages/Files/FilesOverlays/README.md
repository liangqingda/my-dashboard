# FilesOverlays

文件页的两层浮层：业务弹窗（`FilesModals`）与预览层（`FilesPreviewLayers`），按层级摆好——弹窗在下、预览在上。

## 职责边界

- 只做摆放与拼装：状态与动作仍由页面层 hook 持有，这里不新增任何状态。
- 把「扁平 props 一个个传下去」收在这一层，页面正文才只剩列表本身；弹窗 / 预览内部的编排归各自目录。

## 为什么拖拽层不在这里

拖拽层的待拖拽区全屏时就是内容区左侧一列，得跟列表一起排在内容区那一行里（见 `FilesDragLayers`）；跟随指针的影像与飞行动画是 `fixed`，挂在那儿不影响排布。别把拖拽层挪进浮层这一层。

## 坑

- 新增弹窗 / 预览入口时，先判断它属于「业务确认弹窗」还是「预览浮层」，分别进 `FilesModals` / `FilesPreviewLayers`，不要在本层直接拼 JSX。
- 本层只拆包转发；出现新的业务判定逻辑说明该上提到 hook 层。
