# Files

文件浏览页：按 macOS 目录网格展示本机指定目录下的子文件夹、应用包与文件，不限文件类型。

## 页面编排

- **取数与状态**：目录读取 `useFilesDir`；筛选 / 视图形态 / 分组折叠 / 类型过滤 / 导航各有专属 hook；设置持久化 `useFilesSettings`。
- **列表**：`FilesWorkspace` 这一行并排待拖拽区（`FilesDragLayers`）与列表（`FilesEntries` → `DirectoryGrid` / `FilesTable`）。
- **浮层**：`FilesOverlays` 下分业务弹窗 `FilesModals` 与预览层 `FilesPreviewLayers`；安全锁 `FilesLockGate` 挡在正文之前。
- **拖拽**：`useFilesDrag` 按设置分叉到「弹窗挑目标」（`useDragMove` 会话）与「直接拖到文件夹」（`useDirectMove`）两套；待拖拽区状态归 `useDragPending`。

## 主要交互口径

- 点文件夹进下一层，面包屑回退，`⌘↑` 回上一级；可收藏常用目录，收藏面板点选直达。
- 网格列宽下限在设置面板「瓦片最小宽度」里调（120–240，默认 168）；应用目录仍走定宽 132，不随设置变化。
- 拖起条目开移动弹窗（设置可改直接拖）；目标自己在待拖拽区时那一格是禁用落点。
- `⌘` + 点击＝按打开走（文件夹进下一层、图片 / 视频进预览），攒批到一半也能跳出去；没有打开动作的文件
  （pdf / markdown / 压缩包）`⌘` 不给额外语义，与普通点击一致。`Shift` + 点击连选；
  待拖拽区已非空时普通点击＝加入 / 移除条目，整批搬走归待拖拽区底部按钮。
- 点视频在弹窗播放（设置可交外部播放器），点图片同形预览；翻篇与列表点选基于当前目录同类列表。
  打开时先把网格那张缩略图挂成 `<video poster>` 摆出来，首帧解出来之前不是黑底转圈。
- 两扇预览各有一颗「加入 / 移出待拖拽区」（图片在 header、视频在控制栏；两处都排在设置类按钮之前——图片在墙纸右边、视频在设置左边），
  看大图 / 看视频时不用回网格按修饰键点，也能把当前这条收进这一批、或再点一次撤出去。
  已在里面时亮成强调色。动的时候待拖拽区不浮出来（它比预览弹窗高一层，露出来会压住画面），
  只弹一条 `notifications` 提示「已加入共几项 / 已移出剩几项」；关掉预览面板才出现。
  攒批与搬走仍归 `useDragPending` / 移动弹窗。
- 图片预览 header 可进裁剪：保存按设置「替换源文件」或另存到同级 `<文件名> - 裁剪/` 目录
  （文件名 `<文件名> - N.<扩展名>`，N 递增）；写盘与刷新目录由 `useImagePreview` 收口，
  接口契约见 `docs/local-repo-data.md` 的「图片裁剪」。
- 应用 hover 出卸载按钮，二次确认列出残留后删整包并清理缓存 / 配置 / 数据。

## 边界与坑

- 目录读取走 Vite 中间件，仅开发模式可用；写操作同受此限。
- 安全锁密码原样存 localStorage，无哈希、无强度校验，是本机单机防君子性质，不是加密存储。
- 条目数量整份在客户端，不做分页 / 虚拟滚动；不做后台定时轮询，只在进页面、重新可见 / 聚焦、手动刷新时取数。
- 瓦片缩略图按 `useThumbImage` + `utils/thumb-slots` 限流（同时最多 2 条在途，且只排进了视口的瓦片）：
  缩略图是后端现转的，一个要近一秒，十几片瓦片一起发会把浏览器到本机的 6 条连接占满，
  这时打开视频就得排队；其余 4 条连接留给媒体与大文件请求。
- 新增条目动作先在对应 hook 收口请求态与文案，页面只做数据拼装与状态编排；组件 / hook 规格写各自目录的 `README.md`。
