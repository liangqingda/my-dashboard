# FilesPreviewLayers

页面级预览弹层：视频与图片两扇弹窗的装配与挂载。

## 职责边界

- 数据、开关与回调都来自页面的预览 hook（`useVideoPreview` / `useImagePreview`）；这里只负责「什么状态下挂哪一扇、怎么把删除请求转给确认层」，免得页面正文被两段几乎同形的弹窗 JSX 撑大。
- 图片 header 的墙纸与「加入待拖拽区」也在这里转给页面：弹窗只报「要当前这一张」，路径 / 名称从 `image.activeItem` 取，攒批与否归页面。
- 预览层会锁住删除 / 墙纸确认弹窗（预览打开期间不另起业务确认），锁态口径在本层与页面配合处。

## 坑

- 预览列表基于当前目录的同类条目翻篇；条目被删时由 hook 的 `skipDeleted*` 切到下一条，本层不自己算位置。
- 存储作用域走 `FILES_STORAGE_SCOPE`（两扇预览的全屏 / 偏好各记一套），不在组件内手拼存储键。
