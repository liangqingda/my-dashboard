# FilesStates

列表区三种「还没有内容」的状态：读目录失败、首次 / 切目录加载中、空态与未选目录的引导。

## 职责边界

- 只按状态挑一档渲染；取数与判定都在页面里，本层不记 loading / error 状态。
- 四种状态互斥，页面只挑其中一种传 `true`：`error`（失败原因）、`gridSkeleton`（网格骨架）、`tableSkeleton`（表格骨架）、`prompt`（未选目录引导）。

## 坑

- 骨架形状跟着当前视图形态走（网格 / 表格两套），别共用一套骨架占位。
- 新增空态分支先确认属于「加载 / 失败 / 空 / 引导」哪一档，判定口径留在页面。
