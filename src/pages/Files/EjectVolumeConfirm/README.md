# EjectVolumeConfirm

推出外接盘第一次确认：先释放本站打开的读流，再安全卸载；若还有别的程序占着这块盘，落到 `VolumeBusyConfirm` 第二次确认。

## 职责边界

- 基于 `ConfirmModal` 壳；卷名 / 挂载点由 `useVolumeEject` 的 `target` 给，本层只展示「要退哪一块盘」。
- 系统进程与别的用户起的进程只列出、不做动作；结束占用进程是第二次确认的事。

## 坑

- 确认前先关预览（`onBeforeEject`）：还开着的视频会继续请求盘上的字节，刚放掉的句柄立刻又被拿回去。
- 推出成功后的目录回落由 hook 算（默认收藏恰好在要退的盘上就退回主目录），本层不判路径。
