# WallpaperConfirm

设为桌面墙纸确认：会立刻替换这台 Mac 所有桌面空间、所有屏幕的背景，不修改图片、也不删原文件；随时可以在系统设置里换回来。先问一句再动手。

## 职责边界

- 基于 `ConfirmModal` 壳；图片名 / 路径由 `useWallpaper` 的 `request` 给，确认动作交回 `confirm`，取消走 `cancel`。
- 请求态 `loading` 控制确认按钮转圈禁用；成功 / 失败提示由 hook 弹全局通知。

## 坑

- 文案必须写清「所有屏幕 / 所有桌面空间」，别让用户以为只换当前显示器。
- 不复制、不移动原图；原图仍在原目录。
