# FilesEntries

列表区：按当前展示形式把筛选后的文件夹 / 应用 / 文件铺成网格或表格，两种形态共用同一套拖拽与打开回调。

## 职责边界

- 滚动只发生在这一块里，纵向滚动条浮在内容之上；右侧固定留出一段比常规内边距更宽的空白，别让滚动条贴住列表内容。
- 切目录取数期间给整块蒙一层轻量 loading（旧内容留在下面，不清空闪烁）。
- 只做形态分流：`isGridView` 时挂 `DirectoryGrid`，否则挂 `FilesTable`；数据与事件由页面 / hook 层传入，这里不做编排。

## 派生口径

- `selectOrder`（连选用的显示顺序，文件夹在前、文件在后）由本层 `useMemo` 派生，网格与表格共用同一份；不要在两个视图里各拼一遍。
- 空白处落手＝搬进当前这一层：落点挂在外框上而不是网格 / 表格上（内容在 `ScrollArea` 里，目录空或条目少时网格只有内容那么高，下面那片滚动视口不属于网格，挂网格上就是死区）。

## 坑

- 这一层 props 面较宽：新增条目动作时先判断能不能在 hook 层收口、只传一个稳定回调，避免同一回调多层透传（判据见 `docs/reuse-boundaries.md`）。
- 派生数组 / 对象必须 `useMemo`，回调必须 `useCallback`，否则下游瓦片 / 行的 memo 被新引用击穿。
