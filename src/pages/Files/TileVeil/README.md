# TileVeil

瓦片 hover 时盖在内容上的玻璃层，三种瓦片（文件 / 文件夹 / 应用）共用同一份观感：模糊底层画面 + 极淡冷色 + 一圈细高光，而不是压一块黑；文字与操作按钮压在它上面。

## 职责边界

- 不自己做 hover 显隐：显隐触发选择器写在各自瓦片的 `.wrapper:hover` 上（`.wrapper` 是各瓦片私有类名），这里只按 `data-tile-veil` 被外部选中。
- 透明度用 CSS 变量 `--veil-opacity` 从设置面板透传，本组件直接落在自己身上；不另读设置。

## 坑

- 三种瓦片必须共用这一层，别在某瓦片里另写一块遮罩样式。
- 遮罩只盖视觉，不拦截瓦片按钮的点击；按钮浮在它之上。
