# DirBreadcrumb

当前目录面包屑：根按路径自动换形态——主目录下以「家」为根（用户名 + 房子图标），外接卷下以该卷为根（卷名 + 移动盘图标），其余以「本机（`/`）」为根；根之下的分段逐层可点，末段是当前目录只展示。

## 职责边界

- 路径根与分段数据归纯函数 `describePathRoot`，这里只排图标、分段与点击事件。
- 点根回到根所在的那一层；中间分段点哪层进哪层，导航动作由页面 `useFilesNavigation` 收口。

## 坑

- 分段可点性 / 根形态判定不写在组件里，新增路径形态先扩 `describePathRoot`。
- 末段当前目录不可点，别给它挂打开事件。
