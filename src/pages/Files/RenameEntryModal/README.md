# RenameEntryModal

条目改名弹窗：名字可能较长，不在瓦片上就地输入，改用弹窗里的多行文本域编辑。

## 交互口径

- 打开即聚焦文本域并全选原名；回车保存，`Shift+回车` 换行；空名或未改动时保存按钮禁用。
- 切换改名对象时由页面用 `key` 重挂载，初始值直接取当前条目名；本组件不自己同步外部改名后的名字。
- 弹窗正文走过渡层延迟挂载，挂载回调时文本域可能还不在 DOM 里，打开后下一拍再聚焦并全选；表单弹窗关掉焦点陷阱，避免外壳把初始焦点留在隐藏节点上。

## 职责边界

- 基于 `ConfirmModal` 壳；`entry`（路径 / 原名 / 类型）来自 `useEntryActions`，提交交回 `onCommit`，取消走 `onCancel`。
- 重命名失败由 hook 弹通知并退出改名态，本层不重试。

## 坑

- 文件名非法字符 / 路径穿越由中间件收口，本层不做文件名校验。
- `loading` 期间保存按钮禁用并转圈，避免重复提交。
