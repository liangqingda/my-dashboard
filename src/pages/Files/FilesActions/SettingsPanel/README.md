# SettingsPanel

文件页设置面板：外观（视图形态、分组展示、瓦片宽度、悬浮玻璃透明度）、拖拽移动走法（弹窗挑目标 / 直接拖）、筛选方式、视频点击后与外部应用、视频封面、预览默认全屏、页面安全锁（密码 + 开关）。

## 职责边界

- 面板只读值、只回调，持久化在页面设置 hook（`useFilesSettings`）里；后续加设置项按主题分组往下追加。
- 外观组（视图形态、分组展示、瓦片宽度、悬浮玻璃透明度）拆在 `AppearanceGroup`，本文件只排其余主题，不再把外观字段写回这里。
- 分组与字段外观走 `FreePanelGroup` / `FreePanelField`，与视频预览设置面板同一套；不手写原生字段。

## 分组口径

- 按主题分组：每组一块浅底色、不描边；组内字段横向排、放不下自动换行。
- 弹层宽度由 `FilesActions` 放宽到 560（一行两组，每个字段约 250px）；高度上限交给 `IconPopoverButton` 的 `maxHeight`，超过一屏在弹层内部滚动，不顶出屏幕。
- 「瓦片宽度」只在网格形态下露出（表格没有瓦片，改了看不到效果）；区间与步长取 `constants.ts` 的 `TILE_WIDTH_*`（120–248，步长 8），滑块值决定列宽基准，实际列宽再由内容区宽度均分铺满（口径见 `DirectoryGrid/README.md`）。

## 坑

- 「外部应用」下拉必须 `comboboxProps={{ withinPortal: false }}`：Mantine 默认把下拉渲染到独立 portal，点选项会被外层 `IconPopoverButton` 的点击外部判定当成点在外面，弹层直接关掉；就地渲染后选项在弹层 DOM 内，选完弹层还在。
- 安全锁密码不做强度 / 格式限制：原样存进 localStorage，只保证「没密码时开关不可开」。这是本机单机防君子性质，不是加密存储；边界写在页面说明里，别在面板上承诺安全强度。
- 新增设置项先查 `useFilesSettings` 已有 codec 与存储键，不另起一套持久化。
