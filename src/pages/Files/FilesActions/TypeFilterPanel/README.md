# TypeFilterPanel

筛选弹层面板：顶部关键词按名称模糊搜索，下方是「全部 + 分类」列表，改动即时生效。

## 职责边界

- 「全部」与分类列表之间用分割线隔开：多选模式下「全部」是复选框（全勾选中、勾一部分半选、一个没勾未选），单选模式下是单选框；多选点某一类即勾 / 取消，单选一次只能有一类。
- 底部重置把分类退回全选并清空关键词。
- 关键词状态在页面层（会话内，不持久化）；分类选中态在 `useTypeFilter`，本层只接线与排布。

## 坑

- 筛选即时生效，不另设「应用筛选」按钮；关键词与分类叠加生效。
- 被取消勾选的类型连同对应文件夹一起隐藏，隐藏口径在列表描述层，不在本层。
