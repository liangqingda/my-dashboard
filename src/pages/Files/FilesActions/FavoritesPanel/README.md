# FavoritesPanel

收藏目录弹层面板：每条收藏点直达；右侧一颗固定图标（固定 / 未固定两种样式，只靠实心与描边区隔、不额外上色），未固定条目另有移除按钮。固定项排在最上面、不显示移除按钮，与下方未固定项之间用分割线隔开；其余条目可拖拽排序。

## 职责边界

- 列表数据、固定状态与排序持久化归 `useFavorites`，这里只排布与条目事件。
- 条目两行：目录名在上，完整路径在下；路径过长省略，hover 显示全文。
- 「系统应用程序」只是首次预置的一条已固定收藏，取消固定 / 改名之外的编辑与其余条目一致。

## 坑

- 拖拽排序只在未固定项之间生效；固定项不参与排序。
- 收藏路径过长走 `FreeTruncatedText`，不自己写省略样式。
