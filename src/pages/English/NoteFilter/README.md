# 笔记筛选面板（`NoteFilter`）

英语笔记预览弹窗里那块筛选面板的规格。**面板本身无状态**：条件由页面持有并持久化
（`pages/English/hooks/useNoteFilter`，两个 localStorage key 见页面 `constants.ts`），
换一篇笔记、刷新页面都沿用上次的条件；面板只负责展示与回传。

## 三档范围（筛选口径在 `pages/English/utils/filter-markdown.ts`）

| 范围 | 留下什么 |
| --- | --- |
| 全部内容（`all`） | 全部小节，只叠加关键词 |
| 只看习题（`exercise`） | 只留 `### <题号>. <题型>` 题目块，藏掉基础信息表、讲解、每轮的复习统计表 |
| 只看错题（`wrong`） | 题目块里 `**判定**` 不是 ✅ 的（❌ 与 ⚠️ 都算；没写判定的不算错题，不硬塞进来） |

关键词与范围**叠加**：块内任意文本（含标题）命中才保留。命中块之外的祖先只保留标题行，
所以「只看习题」时仍能看到「·复习」「本轮习题」这类层级，用来定位是哪一轮。

## 行为

- 改动即时生效，不需要点「应用」；改的是预览，不改笔记原文（面板底部写明这一点）。
- 一条都不命中时，由弹窗在正文区提示「没有符合当前筛选条件的内容」（不在面板里报）。
- 「重置」回到「全部内容 + 空关键词」；没有条件生效时置灰。
- 弹层由弹窗的 `FilterButton` 渲染，本组件只管里面的控件。
