# 列表筛选面板（`NotesFilter`）

英语练习页 header 上「筛选笔记」按钮点开的那块面板。**面板本身无状态**：条件由页面持有并持久化
（`pages/English/hooks/useNotesFilter`，三个 localStorage key 见页面 `constants.ts`），
刷新页面重新进入后沿用上次的条件；面板只负责展示与回传。

与预览弹窗里的 `NoteFilter` 的分工：**这一份筛列表显示哪些笔记**，那一份筛预览正文；
两者条件互不影响，也各自记各自的存储键。

## 两个筛选项

| 筛选项 | 控件 | 口径 |
| --- | --- | --- |
| 时间范围 | `Select` 一档：全部时间 / 最近 1 小时 / 最近 1 天 / 最近 1 周 / 最近 1 个月 / 指定日期 | 按笔记更新时间算；「最近 N」按日历单位回退（1 小时 = 60 分钟，1 个月 = 往前一个日历月） |
| 指定日期 | 时间范围选到「指定日期」时，日历（`DatePicker`）直接摊在下面 | 只留选中那天 00:00–23:59 更新过的笔记；切档时没选过日期就落到今天 |
| 分类 | `Select`：全部分类 + 记录仓库的分类清单 | 分类键与看板列同源，记录仓库加一个分类，下拉自动多一项 |

- 两个维度是「与」关系；**时间未知**（更新时间解析不出来）的笔记在时间档位下一律不出现，
  不硬凑进「最近 N」。
- 分类下拉的取值有两个占位：`__all__`（全部分类）与 `__uncategorized__`（未分类）。
  状态里空串表示「不按分类筛」，而「未分类」笔记的分类键恰好也是空串，
  所以下拉里要换一个值指代它（见页面 `constants.ts`）。
- 下拉的 `comboboxProps.withinPortal` 必须为 `false`，日历用内联的 `DatePicker`（同样不带弹层）：
  面板本身已是弹层，再套一层 Portal 会被弹层的「点在外面就收」判成外部点击。
- 改动即时生效，不需要点「应用」；底部写明「只影响列表，不动笔记」。
- 「重置」回到「全部时间 + 全部分类」；没有条件生效时置灰。
- 筛空时列表给的是「没有符合当前筛选条件的笔记」（`NotesPlaceholder` 的 `filtered`），
  不再误报「笔记目录里还没有 Markdown 文件」。
- 分类筛到某一类时，看板只留这一类那一列（其余列不再陪着一片「这一列还没有笔记」）。
