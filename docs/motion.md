# 动效：曲线、时长与只动什么

范围：CSS `transition` / `@keyframes`、Web Animations（`element.animate`）、Mantine
`transitionProps`。新写任何动效先按本文件选档；用户点名要某个特别动画时才偏离，
并在改动处注释说明「为什么不走默认档」。

## 曲线只有一套

全站只有五档语义曲线，改一处必须两处同改：

- CSS：`src/styles/global.scss` 的 `--app-ease-*`
- JS：`@/utils/motion-easing` 的 `MOTION_EASING`

| 令牌 | 判据 |
| --- | --- |
| `standard` | 常规状态变化：颜色、背景、边框色、阴影、透明度、小元素位移、淡入淡出 |
| `emphasized` | 有方向的大位移：整条滑出、飞入落点、换窗滑入、展开 |
| `layout` | 布局尺寸变化：宽度、`flex` 分配、折叠高度 |
| `exit` | 退场 / 收起 / 折叠 / 滑出：起步慢、收得进去 |
| `spring` | 落点回弹：只给「图标由小长到落点」这类一步到位的收尾 |

- 业务样式与动画参数里禁止裸写 `cubic-bezier(...)`、`ease`、`ease-out`、`ease-in`。
- `linear` 只给持续旋转的等待指示；循环呼吸类用 `standard`。
- 只变透明度 / 颜色时也用 `standard`，不另起一条曲线。

## 时长按「变化面积 / 距离」分档

| 变化范围 | 时长 | 判据 |
| --- | --- | --- |
| 组件库自带的菜单、提示浮层 | 80ms | 保持组件库默认，不覆盖 |
| 颜色 / 文字 / 背景 / 阴影 / 行状态 | 100–140ms | 只换色、不挪位置 |
| 小元素位移、浮层显隐 | 140–180ms | 位移不超过自身尺寸 |
| 面板、抽屉、布局尺寸、毛玻璃加深 | 200–260ms | 整块在动，或尺寸在变 |
| 整屏移动、程序坞条、窗口展开 | 360–420ms | 同一时刻只允许一个 |
| 跨区域飞行（列表 ↔ 待处理区、收进程序坞） | 520–560ms | 距离跨越大半个屏幕时才算 |
| 循环指示 | 900ms 旋转 / 1600ms 呼吸 | 只表达「还在进行」 |
| 一次性提示停留 | 3s | 自动淡出，不打断操作 |

时长不设全局令牌：同一语义在不同面积下就该不同；跨处复用的时长常量留在各自的
`constants.ts`。

## 只动这两类属性

- 首选 `transform` / `opacity`；其次颜色、背景、边框色、阴影、`backdrop-filter`。
- 不动 `width` / `height` / `top` / `left`。确需过渡布局尺寸时，用 `flex` / `max-height`
  这类能被撑开的量，外层配 `overflow: hidden`，折叠起始高度按实测值钉住（判据见
  `best-ui-interactions` 的折叠动画一节）。

## 进和退不是一条

- 进场可以慢、可以有过冲（回弹只落在终点）；退场更快，只做淡出 + 轻微缩放，不做大位移。
- 退场时长不超过进场。
- hover 进入的延迟只挂在「进」的那一态；指针离开立刻按基础态收回。
- 循环与提示类动画只表达状态，不用来表达「可点」「加载完成」。

## 从哪开始，回到哪

- 有触发点的开合，起点取触发元素（或指针落点）的矩形，终点是它自己就位后的矩形；关闭沿
  同一条路径反向回到**同一个落点**，不许去时一个终点、回时另一个。
- 取不到触发点（键盘触发、会话恢复、全屏铺开）就不做几何位移，只淡入淡出。
- 页面内切换（翻篇、换窗）沿用户的来向进出：下一块从来向一侧进、上一块往反向出，两块同时
  在场，旧块先离场。
- 跨区域搬运（收进程序坞、拖进待处理区、放回文件夹）从源块中心飞到目标格中心；落地后由
  目标真身接管，飞行用的克隆随动画一起销毁，不留在 DOM 里。
- 起点与落点必须实测（`@/utils/motion-geometry` 的 `shiftBetweenRects`），不按设计稿估；
  起点不放在屏幕外——从图标长出来就从图标中心起，不做贴边漏斗。
- 同一次开合只允许一条几何路径，两层不得各播一套。

## 起点用标记，不逐帧写 JS

- 开合、拖拽、选中态写在 `data-*` / class 上，由 CSS 过渡；JS 只负责切状态。
- Web Animations 只用于「起点 / 终点必须实测」的几何动画（从哪个点长出、飞向哪一格）；
  播完清掉内联 `transform` / `opacity` / `will-change` 并 `cancel()`，不让 `fill: both`
  的终态留在 DOM 上。
- `will-change` 临时加、结束删；常驻只允许媒体层与毛玻璃层（避免首帧闪出未虚化画面）。

## 减少动态必须由动画自己兜底

- JS：进入动画前先查 `prefersReducedMotion()`，命中就直接给终态并回调。
- CSS：含 `transition` / `animation` 的块必须带 `@media (prefers-reduced-motion: reduce)`
  分支，把 `transition` / `animation` 置 `none`；退场仍需保持可见性时，只留 `opacity` +
  `visibility`。
- 全局只关 `scroll-behavior`，不做一刀切禁用——否则漏写的块会被一起掩盖。

## 新增动画自查

1. 曲线引用令牌（CSS）或 `MOTION_EASING`（JS），没有裸曲线与关键字；
2. 时长落在上表对应档；
3. 含过渡 / 动画的块有 reduce 分支，JS 动画有短路；
4. `transition` 逐属性写，没有 `all`；
5. `pnpm lint` 通过。
