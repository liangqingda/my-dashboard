# 程序坞：应用级窗口层

把「收起的弹窗」变成一个跨页面、跨刷新都还在的程序坞条目，点条目按快照重建窗口。
它是应用级能力（`DockProvider` 挂在 `App` 的 Router 内、布局外），页面组件不参与恢复。

## 谁能收起

只有**阅读类窗口**接程序坞：`MarkdownPreviewModal`、`RecordDetailModal`、
`ImagePreviewModal`、`VideoPreviewModal`。它们都是「看内容」的窗，收起再打开仍是同一份内容。

确认 / 短表单类弹窗（`ConfirmModal`、删除确认等）**不接**：它们属于 macOS 里 sheet 的语义，
关掉即完成决定，没有「先收起来待会儿再点开」的状态。要接入就必须同时提供可序列化快照与恢复渲染器，
不能只加一颗按钮。

## 描述符与快照

业务弹窗通过 `FreeModal` 的 `dock` 传一份 `DockDescriptor`：

| 字段 | 契约 |
| --- | --- |
| `id` | 稳定且跨页唯一；同一扇窗重复收起只替换这一条。由「窗口种类 + 页面标识 + 内容标识」拼成 |
| `kind` | 四种阅读窗口之一，决定恢复时用哪个渲染器 |
| `title` | 程序坞 tip 与恢复窗口的标题 |
| `snapshot` | 只放可进 localStorage 的字段；恢复时不依赖任一页面状态 |
| `origin` | `page`（默认）收起后要执行 `onClose` 清页面状态；`dock` 再收起只回坞、不删条目 |
| `disabled` | 当前不可收起（编辑中 / 全屏 / 上层确认开着）：按钮保留但置灰 |

快照里能放什么由窗口类别决定：Markdown 存整篇原文；记录详情只存 `recordId` 与标题、正文按 ID 自取；
图片 / 视频存整个目录的最小字段与当前条目（视频多一张封面）。条目最多 8 条，超出按 `createdAt`
淘汰最旧的，避免 localStorage 被快照撑爆。

## 恢复与状态

- 条目里只有 `kind + snapshot`，恢复时按 `kind` 动态 import `src/dock/windows/` 下的渲染器；
  所以切到别的页面、刷新之后都能点开，页面路由不参与恢复。
- 恢复出来的窗口**只保留阅读能力**：编辑、筛选、删除、裁剪、截图、外部打开这些动作依赖原页面的
  回调与文件位置，不在快照里，对应的入口在恢复窗口里不出现。记录详情与图片 / 视频的翻篇由窗口自己的
  状态负责，翻到哪一条会在再次收起时写回快照。
- 页面里的弹窗收起后立即 `onClose`：宿主页面的状态不能留着一半，否则下次从页面打开会撞上旧状态。

## 层级

层级只在 `src/dock/constants.ts` 定义，业务侧不各自写 `z-index`：

| 层 | z-index |
| --- | --- |
| 普通弹窗 | 200 |
| 二次确认 | 320 |
| 服务页全屏拖拽 | 700 |
| 通知 | 800 |
| 恢复出来的程序坞窗口 | 1000 |
| 程序坞条 | 1010 |
| 收放动画的克隆层 | 1150 |
| Tooltip | 1200 |

由此得到两条硬约束：程序坞条必须压过所有弹窗遮罩，遮罩盖不住它；恢复窗口要压过页面里已经开着的
弹窗（含 700 那档全屏拖拽）。Tooltip 在 `MantineProvider` 里统一抬到 1200，否则窗口 header 上的图标 tip
会被 1000 的窗口盖住。

## 悬浮与位置

程序坞是**悬浮层**，不向页面要空间：`BasicLayout` 的 Header / Navbar / Main 保持原尺寸铺满，
程序坞用 `fixed` 停在四条边之一，盖在内容上方。停左 / 右时竖向垂直居中，停上 / 下时横向居中；
盒子始终是固定亮色毛玻璃，不跟主题变深，只受全局毛玻璃浓度影响。

- 没有条目时不渲染整条程序坞，页面上不留任何占位；自动隐藏时整条滑出屏幕。
- 遮罩层级低于程序坞（1000 < 1010），所以弹窗遮罩不会盖住它，收起 / 切窗时仍能点程序坞。

## 一次只开一扇

Provider 只维护一个 `windowSlot`，它自己带 `phase`（`opening` / `closing`）与 `removeOnExit`：

- **点同一图标**：当前窗就把它当场缩回程序坞（`removeOnExit: false`），条目保留；再次点击再展开。
  程序坞恢复出来的图片 / 视频带稳定 `dockId`，窗内翻篇只换快照、不换根节点；收起后下次展开
  仍停在最后看的那一张。Provider 另按 `origin + kind` 兜底认窗，翻页不会多出图标。
- **点另一图标**：不经过「先回坞、再出来」，直接把 `windowSlot` 换成新窗口，按 `animate: 'swap'`
  在原位淡入；旧窗口卸载、新窗口接管同一个位置。
- **关闭（X / Esc）**：`removeOnExit: true`，收起动画结束才删条目；最小化与关闭共用同一个宿主，
  收起阶段 React 复用原组件实例，不重新挂载。
- 收起动画进行中（约 420ms）忽略其它程序坞点击，避免两套状态同时抢窗口。

## 动画

`src/dock/utils/dock-motion.ts` 是收放 / 切换的唯一实现处；「页面弹窗立即卸载」用的克隆飞入单独在
`src/dock/utils/dock-fly.ts`，两边共用同一组关键帧与落点测量，业务层不写动画：

- 页面弹窗收起：量源框体 → 等程序坞项目出现 → 克隆框体 fixed 定位，边位移边非等比缩放，
  同时用 `clip-path` 把远端收成漏斗，最后一帧收成落在图标中心的方块；原窗口立即卸载。
  落点图标打 `data-receiving` 触发回弹。
- 程序坞窗口收起 / 打开：作用在**真实框体**上（`shrinkWindowToDock` / `growWindowFromDock`）。
  关键帧按贴程序坞那条边取 `transform-origin`，平移量按原点换算，保证终点精确落在图标上；
  展开前先把框体 `opacity: 0`，等动画第一帧接管，避免闪一帧终态。
- 切换窗口：`swapWindowInPlace` 只做 200ms 的原位淡入 + 轻微缩放，不再来回飞。
- 遮罩跟着框体一起淡入 / 淡出（`dock-overlay.ts`），开窗时从透明长到原样、收窗时反过来，
  不让背景在窗口飞行途中硬切。
- `prefers-reduced-motion: reduce` 时全部跳过，只做即时挂载 / 卸载。

## 设置与存储

全局设置面板在系统顶栏（`settings-panel`），读写 `app:dock-settings`；收起条目存在 `app:dock`。

- 位置：上 / 右 / 下 / 左，默认右；图标大小、hover 放大倍数、自动隐藏都在「程序坞」这一组里。
- 自动隐藏：隐藏后由顶栏的图标按钮唤出 / 收起；`revealed` 只影响可见性，不删条目、不占布局。
- hover 放大按指针沿停靠轴到各图标的距离算倍率（越近越大），位置保持不动；
  图标本身是彩色圆角 app 图标，当前展开项下面有运行小点。
- 文件页的图片 / 视频瓦片 hover 时可直接「收起到程序坞」：不打开预览，用 `collect` 把当前目录的
  同类列表与这一条的快照交给程序坞，恢复后仍是完整预览。
- 全局毛玻璃浓度：Provider 把 `40%–100%` 写到 `<html>` 的 `--app-glass-strength`，`global.scss` 里
  `--app-glass-*` 用 `color-mix` 乘上它；程序坞底板固定用白色玻璃乘这个浓度，不跟主题变深。

## 快捷键与关闭口径

`⌘M` 收起当前最上层、可收起的弹窗。键位监听放在 `layouts/BasicLayout`（结构检查只允许
`FreeModal` 与 `layouts/` 监听 keydown）；`FreeModal` 通过 `useDockMinimize` 在打开时把自己登记进
`modalStack`，Provider 的 `minimizeTop()` 返回是否真的收到一扇，没收到就把键让给浏览器。

对能收起的弹窗，**只有 X 与 Esc 是关闭**（删条目）；点遮罩与按空格都是「收回到程序坞」：
`FreeModal` 在 `dock` 可用且未禁用时把遮罩点击与空格的 `onDismiss` 交给 `minimizeToDock`。
不可收起（编辑中 / 裁剪中 / 全屏等）时这两下只做无动作，不会误关窗口。
页面弹窗收起后仍会执行 `onClose` 清掉页面状态；程序坞恢复出来的窗口则只回到图标。

## 新增一类可收起窗口要动的地方

1. `dock/types.ts` 的 `DockWindowPayload` 加 `kind` 与快照类型（判别联合）；
2. `dock/utils/dock-entries.ts` 的编解码补这一支，坏项一律返回 `null`；
3. `dock/windows/registry.ts` 加动态 import；
4. 新增恢复渲染器：只传快照与 `onRequestClose`，`dockOrigin="dock"`；
5. 业务弹窗接 `dock` 描述符：`id` 稳定、`snapshot` 可序列化、`disabled` 覆盖「不能收」的状态；
6. 本文件补契约与已知限制。
