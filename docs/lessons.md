# 常见问题经验积累

开发与自审中反复出现、工具规则兜不住、容易返工的小坑；每条直记现象与修法，处理完即补。
新条目按出现顺序追加，不展开事故复盘。

## 收录标准

- 同类问题第二次出现，或自审时容易再犯的 UI / 交互细节；
- `eslint` / `check-structure` 等工具已经能拦的（命名、行数、越层、省略号归属）不记；
- 一次性业务决策、某页面专属规格不记，归对应 `docs/` 或组件 `README.md`。

## 条目

| 场景 | 现象 | 修法 / 判据 |
| --- | --- | --- |
| 跨列的分组 / 标题行（`colSpan` 铺满整行） | 标题文案落在首列，没随整行对齐 | 跨列行的标题要整行居中（或明确对齐档位）；共享标题组件提供对齐参数，别把对齐写死在某一处 |
| 整行可点的折叠行，行内再放可点按钮 | 点按钮触发两次切换（行 `onClick` 与按钮 `onClick` 冒泡叠加） | 内层按钮的点击先 `stopPropagation`，外层行的同一切换动作才不会被点两遍 |
| 居中排列的 flex 行里混了图标 + 文案 | 文案 `flex: 1` 拉伸后，图标被顶到一侧，整体看起来没居中 | 居中单元里文案不要拉伸（`flex: 0 1 auto`），图标与文案作为整体交给容器 `justify-content: center` |
| 表格自定义行改了上下 `padding` | 上下留白不对称，标题 / 图标视觉偏上、行底留白偏大 | 上下留白用对称的 `padding-block`；垂直居中沿用单元格默认 `vertical-align: middle`，别在业务里重复声明 |
| 整行 / 整段 hover 高亮只挂在内部按钮上 | 悬停在行内边距、间隙处时高亮不触发；反过来选择器放宽又会带起段内其它按钮 | 高亮色挂在祖先行 / 段的 `:hover` 上向下传；选择器限定直接子级标题按钮（`> button`），别用后代选择器扫到瓦片操作按钮 |
| 网格分组折叠动画（flex 列 + grid 壳） | `0fr` / 直接写 `height` 在这套布局里收不拢，收起后瓦片整排露出 | 用 hook 按实测 `max-height` 钉住起始高再过渡到 0；收起态样式表 `max-height: 0` + 内层 `overflow: hidden`。别写 `overflow-clip-margin: 0`（压缩器当初始值删掉、规则变空）。后台隐藏标签页 CSS 过渡会冻结，别据此判断动画失效 |
| 弹层开着时点底层画面 / 行 | 弹层在 `mousedown`（`touchstart`）阶段先被点外判定关掉，落到 `click` 时状态已翻成关，点击回调又把底层动作（播放 / 暂停）触发一遍 | 开合意图在指针按下那一刻记进 ref，`click` 先按这个手势判断收弹层，再读实时状态兜底；别只靠 `click` 那一刻的 `open` 状态 |
| 外壳把状态经 context 下发给页面内部 | 在页面组件本体的顶层读这个 hook，永远拿到默认值（全屏了仍按非全屏走），改了半天「没变化」 | Provider 包在 `children` 外边，页面组件是它的父级；读状态的那一层必须是自己作为 `children` 挂进外壳的组件（示例：`FilesWorkspace`）。改完先看真机 DOM 上目标类名有没有出现，别只信 typecheck |
| 页面根带 `z-index`（全屏那种 `position: fixed` 铺满）时，页面内部再放「压在弹窗之上」的浮层 | 非全屏一切正常，全屏后浮层整片不见（被弹窗遮罩盖住），`z-index` 调到 999 也没用 | 页面根的 `z-index` 把内部所有浮层关进同一个层叠上下文，与弹窗的 `z-index` 不再同级比较。这种浮层用 `<Portal>` 挂到文档级，别在页面里加码 |
